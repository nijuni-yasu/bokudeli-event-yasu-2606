# 14_競合調査 README

世界のイベント告知・集客・コミュニティ系サービスと、飲食店向け SaaS を調べ、Shokujii の**機能開発とグロース施策の意思決定**に使うための調査資料。

- **調査(事実)と意思決定(判断)を分ける。** 調査文書は事実と出典を残し、判断は `60_意思決定/`(未作成)に置く。判断は変わりうるが、事実の記録は残す。
- 調査日は 2026-10-11 時点。料金・買収・サービス終了は変わるため、更新ルールに従って見直す。

## 信頼度タグの凡例

| タグ | 意味 |
| :-- | :-- |
| [事実] | 出典で確認できた |
| [推測] | 調査担当または執筆者の解釈 |
| [不明] | 確認できなかった(推測で埋めない) |
| [自社主張] | 企業自身の数値で、第三者検証がない |
| [競合発信] | 競合企業のブログ等。利害関係がある |
| [二次] | 報道・第三者の解説で確認し、公式では未確認 |
| [要約] / [検索要約] | 検索結果の要約だけで確認し、本文を読めていない |
| [要確認] | 資料間で食い違う、または原典を確認できていない |
| [推計] | 第三者の推計値 |

機能マトリクスの判定値は ✅(あり)/ △(一部・有料・条件付き)/ ❌(ないと確認)/ ？(確認できず。**非対応を意味しない**)。定義は [機能タクソノミー](./30_機能比較/01_機能タクソノミー.md) を参照。

## 更新ルール

- **数値は出典URLと時点を付ける。** 食い違う数値は一方を採らず併記する。確認できないものは「不明」と書く。
- **見直し:** 四半期ごと、または主要サービスの料金改定・買収・終了があったとき。
- **マトリクスの更新:** `30_機能比較/data/*.csv` を直し、リポジトリのルートで次を実行して再生成する(手で `02_機能マトリクス.md` を編集しない)。

  ```bash
  python3 -I documents/14_競合調査/30_機能比較/build_matrix.py
  ```

- **新しい調査:** ノートを `90_調査ノート原本/` に保存し、事実を文書へ統合する。原本は編集しない。
- **スクリーンショット・競合の資料:** 社内の検討にだけ使い、外部に公開する資料(LP・営業資料・PR)へ転用しない。
