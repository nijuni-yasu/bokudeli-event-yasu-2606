> 関連: [14_競合調査 README](../00_README.md)

## 読み順

1. 全体像と食い違い: 01 の要約
2. 「儲かる型か」: 02 の試算と感度分析
3. Shokujii への示唆: 07(隙の一覧表と、組み合わせ・罠・検証の順序)
4. 根拠の確認が必要なとき: 03〜06、08

## 扱い

- **数値の大半は創業者・会社の自己申告です。** 登記で確認できる財務は FY2021(売上 0、純損失 約€145,200)だけで、広告費・CAC・継続率・LTV・粗利を出した記事は見つかっていません。
- **試算は [試算] です。** 解約率・広告費の比率などは仮定で、前提は 02 に1つずつ書いてある。
- **ノート間で食い違うものは併記しています。** 特に、店に対価を払うか(店が運営に手数料を払うという報道と、創業者の「交渉しない」)、売上が MRR か ARR か、月15万人の意味、米国の価格の方向。
- **検索ツールが米国向けで、多言語の記事を網羅できていません。** 見つからなかった国・言語(ドイツ語圏、イタリア、オランダ語圏、北欧、トルコ、日本の主要媒体など)は、各文書に「見つからず」と書いた。「存在しない」ではない。
- **Reddit・Google Play・TikTok・YouTube・Instagram は読めていません。** ユーザーの声は Trustpilot、App Store、体験記ブログ、報道が中心。
- **ブレストは [推測] です。** 優先度・工数は断定していない。実験の判定基準は仮。
- **Shokujii の現状に関する前提:** 自社の機能判定(コード確認)では、現行は配達前提の設計で、イートインは仕様書のみで未実装。店で食べる前提のアイデアは、先にイートインの状況を確認する。
