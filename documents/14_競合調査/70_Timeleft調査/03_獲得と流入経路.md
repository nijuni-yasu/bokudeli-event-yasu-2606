調査日: 2026-10-14。Timeleft がどのチャネルで利用者を獲得してきたかを、事実・根拠の強さ・数字の有無に分けて整理した。有料の SNS 広告が主軸である証言は多いが、広告費・CAC・チャネル別比率は誰も公開しておらず、すべて[不明]である。

凡例: [事実]=記事・公式ページ・ストア表示で確認 / [自社主張]=創業者・会社の自己申告 / [推計]=第三者の推計 / [試算]=本調査の計算 / [推測]=解釈 / [不明]=確認できず / [要約]=検索結果の要約のみ / [声]=個人の証言。根拠の強さは、強=独立した複数の出典が一致、中=単一の出典または自己申告が複数、弱=要約のみ・広告記事・競合発信のみ。

## 要約

- **主軸は Instagram/Meta を中心とした有料のソーシャル広告。** サンフランシスコ、バンクーバー、ダーラム、マレーシア、東京など、複数国の記者・参加者が「広告で知った」と書く。根拠の強さは強、数字は[不明]。
- **補強は、創業者個人の発信(Instagram は約100万〜120万フォロワーの自己申告)、買った枠を含む大量の PR 記事、WhatsApp グループなどの口コミ。** 紹介記事の一部は有料枠で、「報道」に見える露出が実際より多い可能性がある。
- **公式の紹介制度はアフィリエイト(専用リンク経由の全売上の50%)。** 期間・資格・収益例は書かれていない。
- **TikTok・インフルエンサー・アプリストア経由の比率・検索流入の比率は確認できない。** Web 訪問は月約26万と小さく、オーガニック検索が最大の Web 流入元(34.09%、推計)である。
- **「広告のみで都市を開く」という主張は誇張を含む。** 都市単位の担当者はほぼ置かないが、国単位の担当者は少なくとも4人実在する。

**整理 [推測]:** 「都市を開く作業(登録を集めて初回の卓を作る)」は広告と自動化で行い、現地人員は置かない。ただし国単位では少数の担当者が店と現地パートナー(ホテル、メディア)を担い、都市単位の窓口(WhatsApp)が一部にある。2024年前半の急拡大期と後半以降で運用が分かれた可能性もある。

## 解釈 [推測]

- 広告の効きは「新しい街で最初の登録を作る」までで、再参加は WhatsApp グループ・同席者との関係・サブスクの習慣に支えられている。
- 「現地チームなし」の成長は、創業者個人の発信力(約100万フォロワー)、Meta 広告の文面の使い回し、孤独というニュース性の三つで成立した。同じ型を再現するには、広告のクリエイティブ運用力と、広告で作れない都市の密度への投資が要る。
- アフィリエイト50%は、広告費(CPA)より高い率を払ってでも成果報酬型の流入を増やす設計で、会社が LTV を高く見ている示唆に見えるが、継続率が[不明]なため断定できない。
- 2025-10 の地下鉄広告は、成長が鈍化した時期に初めてブランド広告へ踏み出したことを示す。SNS 広告の費用対効果が下がっている可能性があるが、根拠は状況証拠にとどまる。
- 日本では、広告を詐欺と疑った例、公式情報が検索で少なく怪しく感じた例があり、獲得の入口で信頼の壁がある可能性がある(個人の声3件)。
