# 主催者獲得:機能と施策

> 調査日: 2026-10-11 / 調査範囲: 世界のイベント告知・集客・RSVP・チケッティング・コミュニティ系サービス(約45サービス、7観点で並行調査)。

> 数値は [事実] / [推測] と信頼度タグ(自社主張・競合発信・要約・要確認)付き。出典間で食い違う数値は併記している。

イベント告知・チケッティング・コミュニティ系サービスが、主催者(イベントやグループを立てる人・店・団体)をどう獲得しているかを、「機能」と「施策」に分けて整理し、コールドスタート戦略の比較と失敗事例を加えた(調査時点 2026-10-11)。結論は四つである。第一に、主催者(供給)はほぼ全社のボトルネックであり、売上は少数の高頻度主催者に集中する。Eventbrite は 2017年に 95%超の主催者が自己登録で、その層が純収益の 54%を生んだ ([目論見書 424B4](https://www.sec.gov/Archives/edgar/data/0001475115/000119312518277997/d618448d424b4.htm))。第二に、手数料と無料枠は最大のレバーで、触ると主催者が即座に動く。Eventbrite が 2023年に無料イベントへ手数料を課して撤回した経緯がその例である。第三に、差別化は価格より「データ・入金・集客・運営の束ね」にある。第四に、「参加者が次の主催者になる」導線は多くのサービスが主要経路とするが、転換率を公開したサービスは見つからなかった。

**読み方**:各項目の「根拠・数値」は調査ノートで出典を確認した [事実]、「前提条件・失敗条件」の多くは [推測] である(事実の場合はその旨を付す)。[自社主張]、[競合発信]、[要約]、[要確認] の意味は、自社の数値、競合のブログ等、検索要約のみで原文未確認、資料間で食い違うか原典未確認、を指す。数値が食い違う場合は併記し、一方を採用しない。

## 主催者の三つの層:自己登録の裾野、高頻度の少数、法人・施設

Eventbrite の目論見書は主催者の獲得経路として、他の主催者からの口コミ、参加者としての利用経験、検索結果での露出、無料イベントで試せること、コンテンツライブラリを挙げ、営業チームは特定カテゴリ・国の主催者を狙う補完にとどまる。前年の主催者群が生んだ手数料ベースのリテンション率は 2016年 93%、2017年 97%である ([424B4](https://www.sec.gov/Archives/edgar/data/0001475115/000119312518277997/d618448d424b4.htm))。2025年 Q3 には有料クリエイターの 13%が有料チケットの約 60%を生むと同社は述べた([決算コール](https://www.marketbeat.com/earnings/reports/2025-11-6-eventbrite-inc-stock) [要約])。2024年 Q2 には有料クリエイターが 177,000(前年 189,000)に減る一方、営業経由の新規予約は約 +60%だった ([Q2 2024 決算コール](https://www.marketbeat.com/earnings/reports/2024-8-8-eventbrite-inc-stock))。[推測] 裾野はセルフサービスで広げ、収益は高頻度の少数と法人が支える二層構造であり、獲得施策もその前提で設計されている。

## 機能カタログ:プロダクトに実装された11の仕組み

### O-F1 作成の軽さと無料公開(low-friction creation)

**実施しているサービス**:Luma、teket、Doorkeeper、Skiddle、こくちーず、Partiful、Eventbrite。

**根拠・数値**:teket は審査不要・最短 5分・メールアドレスのみで公演ページを作れると訴求し ([ASCII](https://ascii.jp/elem/000/004/253/4253597/))、Doorkeeper は「コミュニティを約 5分で作成」、Skiddle は登録「60秒未満」、こくちーずは会員登録だけで作成できる(初期費用・月額なし)と案内する ([Doorkeeper](https://www.doorkeeper.jp/organizers?locale=ja)、[Skiddle](https://promotioncentre.co.uk/landing-page/)、[こくちーず](https://www.kokuchpro.com/)) [自社主張]。Eventbrite は 2026-04 にイベント作成の読み込み時間 -40%、「保存してから公開」を追加した ([公式ブログ](https://www.eventbrite.com/blog/whats-next-at-eventbrite/))。

**前提条件・失敗条件**:[事実] 審査を置く例もあり、豆瓣同城は提出後に約 24時間の審査で広告的内容を不承認とし ([豆瓣ヘルプ](https://help.douban.com/event?app=3))、Luma の Discover は全イベントを載せないキュレーション型である ([Luma ヘルプ](https://help.luma.com/p/searching-for-events))。スパム・低品質イベントの発生率や対策の一次情報は確認できていない [不明]。

### O-F2 参加者名簿・CRM・一斉配信(CRM / messaging)

**実施しているサービス**:Luma、Posh、Doorkeeper、こくちーず、Peatix、connpass、Eventbrite、Meetup Pro。

**根拠・数値**:Luma はカレンダーのフォロワーと連絡先をタグで絞って送信でき、HubSpot・Salesforce 連携は Enterprise である ([Luma ヘルプ](https://help.luma.com/p/luma-calendar-overview))。Posh は過去参加者への SMS が無料・無制限と自社が述べる ([Posh vs DICE](https://posh.vip/university/post/posh-vs-dice) [自社主張])。こくちーずのプレミアム(月 1,000円)は過去参加者・メンバーへのメール配信を含む ([プレミアム](https://www.kokuchpro.com/pages/premium/))。connpass は 2026-11 から全アカウントのグループメッセージに月 7,000通の上限を置き、95%以上のグループは現状で上限内とする ([お知らせ](https://help.connpass.com/announcements/info/20260805))。

**前提条件・失敗条件**:[事実] Luma はコールドメールを禁じ、直近 5日のスパム率 0.025%・バウンス率 3%で警告、0.05%・7%で自動停止とし、停止時の Plus は返金しない ([Luma ヘルプ](https://help.luma.com/p/email-consent-and-cold-emailing))。[推測] 配信量への課金は大規模グループに集中し、配信機能を持つなら同意と停止基準が要る。

### O-F3 入金の速さ・資金繰り支援(payout / working capital)

**実施しているサービス**:Luma、Eventbrite、Posh、TIGET、Peatix、Eatwith、Traveling Spoon。

**根拠・数値**:Luma は Stripe 経由で米国では 2日ローリング、条件を満たせば Instant Payouts とし、Eventbrite は原則イベント後と自社比較で述べる ([Luma vs Eventbrite](https://help.luma.com/p/luma-vs-eventbrite) [自社主張])。Eventbrite は Instant Payouts と事前ペイアウトを持ち、現金 $299.9M のうち $253.6M はクリエイターへの預り金で、前払い・非回収型支払いの残高も計上する ([10-K FY2025](https://www.sec.gov/Archives/edgar/data/1475115/000147511526000005/eb-20251231.htm))。Posh は同日入金と資金前貸しを訴求する ([Posh vs DICE](https://posh.vip/university/post/posh-vs-dice) [自社主張])。TIGET は会場費・制作費の請求書をカード払いにして最大 60日後払いにできる ([IT Business Today](https://itbusinesstoday.com/fintech/finance-tech/tiget-introduces-card-payment-service-for-event-organizers/))。Eatwith はイベントの 2営業日後に支払い ([Eatwith ヘルプ](https://intercom.help/eatwith/en/articles/2680329-how-do-i-become-an-eatwith-host))、Traveling Spoon は体験の少なくとも 8時間前に支払う ([Traveling Spoon](https://travelingspoon.com/support/hosts))。

**前提条件・失敗条件**:[推測] 前払い・前貸しは、キャンセルやチャージバックの負担を誰が持つかとセットになる。[競合発信] Posh のチャージバックは Stripe の紛争手数料 $15で、主催者が負けると残高から引かれるとされる ([TickPick](https://www.tickpick.com/blog/organizer/dice-vs-posh-vs-tixr-vs-tickpick))。

### O-F4 チェックイン・当日運営(check-in / on-site)

**実施しているサービス**:Luma、Meetup、Ticket Tailor、connpass、こくちーず、活动行、Platinumlist、Weezevent。

**根拠・数値**:Meetup は出席者リストと QR チェックイン ([Meetup Product Updates](https://product.meetup.com/))、Ticket Tailor は無料のチェックインアプリ、connpass は出席コードと名簿 Excel を持つ。活动行は大規模向けにゲート・リストバンド・顔認証の機器と現場サポートを提供し ([活动行](https://www.huodongxing.com/management))、Weezevent の 2025年の入場スキャンは 4,100万回と報じられる ([Access All Areas](https://accessaa.co.uk/weezevent-reports-strong-2025-growth/))。

**前提条件・失敗条件**:[推測] 食事会では受付の中心が店舗側になるため、幹事向けの出欠管理と店向けの厨房共有を分けて設計する必要がある。獲得への寄与の定量値は確認できていない [不明]。

### O-F5 分析・流入元の可視化(insights / attribution)

**実施しているサービス**:Luma、Posh、Eventbrite、Peatix、Meetup Pro、teket。

**根拠・数値**:Luma の Insights は登録推移・流入元・誰が人を連れてきたかを示し、主催者に上位紹介者への感謝や早期アクセスを勧める ([Luma ヘルプ](https://help.luma.com/p/promote-your-event))。Posh はチャネル別のトラッキングリンクを持つ ([Posh サポート](https://support.posh.vip/en/articles/10723700-creating-kickback-affiliate-offers-public-private))。Meetup Pro は「RSVP +40%、会員 +50%、エンゲージメント +400%」と自社が主張するが、基準・方法は非開示である ([Meetup Pro](https://www.meetup.com/pro/) [自社主張])。

**前提条件・失敗条件**:[推測] 数字が見えることは「次も開く」動機になるが、小規模イベントではデータが少なく意味が薄い。

### O-F6 共同主催・権限分離・複数管理者(co-host / roles)

**実施しているサービス**:Luma、Doorkeeper、connpass、豆瓣同城、Posh。

**根拠・数値**:Luma は共同ホスト・イベントマネージャーが無制限で、Tech Weeks では「掲載のみ」「共有管理」「中央管理」の 3形態を分け、中央チームが見られるゲストデータは自分が管理するイベントに限る ([Tech Weeks](https://help.luma.com/p/tech-weeks))。Doorkeeper は 2023-01-17 に管理者権限を追加した ([Doorkeeper news](https://www.doorkeeper.jp/news))。豆瓣は発起人と組織者の権限を分ける ([豆瓣ヘルプ](https://help.douban.com/event?app=3))。Posh はパフォーマンス階層に達した紹介者に共同ホストの機会を与える ([Posh affiliate](https://university.posh.vip/university/post/posh-affiliate-program))。

**前提条件・失敗条件**:[推測] 誰が決済と名簿を持つかが曖昧だと、主催者間の摩擦とデータの分散が生じる。共同主催経由で主催者が増える割合は公開されていない [不明]。

### O-F7 API・連携・二重登録の削減(API / integration)

**実施しているサービス**:TECH PLAY、Luma、Eventbrite、Doorkeeper、connpass、Meta、Weeztix、Fever。

**根拠・数値**:TECH PLAY は 2026-08-04 に API を無料公開し、申請・審査なしでトークンを発行でき、背景に「主催者が複数のプラットフォームに同じ情報を個別に登録・更新している負担」を明記した ([PR TIMES](https://prtimes.jp/main/html/rd/p/000000015.000183857.html))。Luma の API は Plus が必要で ([Luma API](https://help.luma.com/p/luma-api))、Eventbrite の App Marketplace は 100超のアプリを持つ ([Eventbrite 機能ページ](https://www.eventbrite.com/features/))。Meta の Official Events API は外部の主催者が複数の Page へイベントを一括公開できる(Humanitix が採用)が、2018-04 に Events API は新規開発者へ閉鎖された ([Meta](https://developers.facebook.com/products/official-events-api/)、[Facebook for Developers](https://developers.facebook.com/blog/post/2018/04/04/facebook-api-platform-product-changes/))。

**前提条件・失敗条件**:[推測] 連携先(Google、Apple Invites、WhatsApp Events)が競合化するリスクがある。連携が主催者獲得にどれだけ寄与したかの定量値は確認できていない [不明]。

### O-F8 インポート・移行支援(migration tools)

**実施しているサービス**:Luma、Ticket Tailor、TECH PLAY、Posh、AllEvents。

**根拠・数値**:Luma は Eventbrite・Meetup 専用の自動移行を持たず、参加者 CSV から招待を送る手順を案内し、大量の移行はサポート相談としている ([Luma vs Eventbrite](https://help.luma.com/p/luma-vs-eventbrite))。Ticket Tailor は Eventbrite 売却後に比較記事を出したが、移行ツール・乗り換えキャンペーンの記載はない ([Ticket Tailor ブログ](https://www.tickettailor.com/blog/bending-spoons-acquires-eventbrite-what-does-this-mean))。AllEvents は Google イベント掲載の申請支援ツールを持つが、Facebook 連携・イベントインポートの記載はない ([AllEvents](https://allevents.in/pages/event-ticketing))。離れる側では、OWASP が Meetup を廃止して自サイトのカレンダーに移し、RSVP や過去参加者へのメールは当初未実装だった ([OWASP](https://owasp.github.io/blog/2026/01/13/retiring-meetup))。

**前提条件・失敗条件**:[推測] 移行コストが下がっても、競合の発見面(検索・アプリ経由の集客)に価値を置く主催者は移らない。実際に乗り換えた主催者数の独立した数値は見つからなかった [不明]。

### O-F9 運営の束ね(キャッシュレス・飲食の事前選択・許認可)

**実施しているサービス**:Weezevent、Howler、Shotgun、Passline、Platinumlist、SevenRooms、Tock、Fever。

**根拠・数値**:Weezevent はチケット・入場管理・キャッシュレス・スタッフ管理を 1つのスイートにまとめ、Passline は飲食の事前販売(preventa de consumo)を持つ ([Access All Areas](https://accessaa.co.uk/weezevent-reports-strong-2025-growth/)、[Infonegocios](https://infonegocios.com.py/default/passline-la-plataforma-de-autogestion-de-eventos-busca-expandirse-a-nuevos-rubros))。Platinumlist はドバイ・カタールのイベント許可申請の代行、スタッフ手配、チケット印刷まで束ねる ([Platinumlist](https://platinumlist.net/for-organisers/))。SevenRooms は、メニューの事前選択、未選択者への自動リマインド、厨房への集計共有、デポジットを持ち、前払い体験で per-cover 支出が平均 +50%と自社が述べる ([SevenRooms](https://sevenrooms.com/platform/events-experiences/) [自社主張])。

**前提条件・失敗条件**:[事実] 店舗向け SaaS の効果数値(SevenRooms の年 $115K+、Tock の「業界最低の no-show 率」、OpenTable の初来店 78%)はいずれもベンダーの自己申告である。

### O-F10 信頼・安全の保証(vetting / protection)

**実施しているサービス**:ストアカ、Airbnb Experiences、Traveling Spoon、Eatwith、Accupass、Withlocals、DICE、RA。

**根拠・数値**:ストアカは講座の審査、講師の本人確認、賠償保険(ストアカ補償)を持つ ([ストアカ会社概要](https://www.street-academy.com/about))。Airbnb Experiences は身元確認、ライセンス・保険、専門性(5年以上の実務等)を求め ([Airbnb](https://www.airbnb.com/resources/hosting-homes/a/whats-required-to-host-airbnb-experiences-743))、Traveling Spoon は「ホストの 100%を個別審査」して自宅での試験体験まで行う ([Traveling Spoon](https://travelingspoon.com/support/hosts))。Eatwith の審査は最大 14営業日である。Accupass は有料イベントの主催者に本人確認と振込口座の登録を求める ([Accupass](https://support.accupass.com/knowledgebase/articles/1885324-the-verification-for-paid-event-%E9%80%9A%E9%81%8E%E6%94%B6%E8%B2%BB%E6%B4%BB%E5%8B%95%E5%AF%A9%E6%A0%B8))。

**前提条件・失敗条件**:[推測] 審査が重いほど供給の増加は遅くなる。Airbnb は「何でも受け入れない」と表明し、質と独自性を優先している ([Arival](https://arival.travel/?p=187663))。

### O-F11 バッジ・プロフィール・ランク(badge / status)

**実施しているサービス**:Eventbrite(Top Organizer バッジ)、문토(Selected Host)、프립(슈퍼호스트)、ストアカ(バッジランク)、당근(動ネ活動家)。

**根拠・数値**:Eventbrite は 2026-04 に主催者プロフィールの刷新と Top Organizer バッジを追加した ([公式ブログ](https://www.eventbrite.com/blog/whats-next-at-eventbrite/))。문토の選抜型「셀렉티드 호스트」は 2024年3月の告知時点で全ユーザーの 0.003%で、ソーシャリングとクラブは誰でも開設できる ([문토 クラブ案内](https://www.munto.kr/notice/detail.html?id=480) [要確認])。프립は月ごとの優秀ホストを「슈퍼호스트」に選び追加の手数料減免を与える ([머니투데이](https://www.mt.co.kr/future/2022/03/07/2022030712570046534))。

**前提条件・失敗条件**:[推測] 入口を広く開けつつ質をバッジで分離する設計で、バッジの基準(販売量・評点・応答率・通報履歴)が公開されていないと不満を生みやすい。

## 施策カタログ:手数料・BD・プログラム・ブランディングの11施策

### O-M1 手数料設計(fee design)

**実施しているサービス**:購入者負担型(Eventbrite、Skiddle、RA、DICE、Billetto、LIVEPOCKET、AllEvents)、主催者控除型(Peatix、こくちーず、EventRegist、Luma)、ゼロ+任意チップ型(Zeffy、HelloAsso)、集客経路別の二層型(ストアカ、Billetto の広告経由 33%)、月額型(Meetup、Doorkeeper)、固定額型(Ticket Tailor)。

**根拠・数値**:ストアカは初回に自己集客 10%・ストアカ経由 30%(対面 20%)、2回目以降はどの経路でも 10%で、持ち込み集客を歓迎しつつ新規送客に高率を課す ([ストアカ料金](https://www.street-academy.com/fee))。HelloAsso の共同創業者は、2015年にチップが収益の 50%を占め B2B をやめられたと述べた ([Carenews](https://www.carenews.com/fr/news/lea-thomassin-le-modele-economique-du-pourboire-correspond-a-l-adn-du-secteur-associatif))。Eventbrite の 2024年の take rate は 9.9%である ([Q4 2024 株主レター](https://www.sec.gov/Archives/edgar/data/1475115/000147511525000025/q4shareholderletterfinal.htm))。

**前提条件・失敗条件**:[事実] Eventbrite の 10-K は、離脱した主催者を取り戻せないおそれをリスクとして明記する。任意チップは初期値が高く「任意」が分かりにくいという不満があり、競合の Donorbox は 25ドル超の寄付で 15%が初期値と述べ、Trustpilot にも「隠れた手数料」の低評価がある ([Donorbox](https://donorbox.org/nonprofit-blog/zeffy-reviews) [競合発信])。

### O-M2 無料イベントの扱い(free event policy)

**実施しているサービス**:Eventbrite、Luma、Peatix、こくちーず、Doorkeeper、connpass、Ticket Tailor、pretix、Universe、Zeffy、teket。

**根拠・数値**:Eventbrite は 2023年に 25人超の無料イベントにも主催者手数料を課し、2024-09-04 に手数料なしの公開へ戻した([Q2 2024 決算コール](https://www.marketbeat.com/earnings/reports/2024-8-8-eventbrite-inc-stock)、[Eventbrite ブログ](https://www.eventbrite.com.au/blog/?p=430197))。Doorkeeper は初回の無料イベントを試せるが、2件目から月額プランが要る ([Doorkeeper 料金](https://www.doorkeeper.jp/pricing))。Ticket Tailor は無料チケットを年 5,000枚まで無料とする(FAQ は 2,000枚で不一致)。pretix は年 500枚まで無料である ([pretix](https://pretix.eu/about/en/pricing))。

**前提条件・失敗条件**:[事実] Eventbrite の目論見書は、主催者の多くが無料の集まりから始めて有料に移ることを獲得経路に挙げる。無料から有料への転換率は公開されていない [不明]。[推測] 無料枠の上限を下げると、入口だった層が離脱する。

### O-M3 参加者データの所有権とプラットフォーム迂回(data ownership / disintermediation)

**実施しているサービス**:Luma、Posh、RA、DICE、ストアカ、Meetup。

**根拠・数値**:Luma はゲスト CRM と CSV の入出力を主催者に渡す。RA のパートナーは「販売データの完全な所有」と証言する一方、競合の比較表は RA を「Partial」、DICE を「No」と評価する([RA Pro](https://pro.ra.co/)、[Ticket Fairy](https://www.ticketfairy.com/event-ticketing/dice-vs-resident-advisor) [競合発信])。ストアカは、講師の連絡先(メール・LINE 公式アカウント・SNS)の掲載、LINE・メルマガ登録を条件にする行為、直接徴収を規約で禁じる ([ガイドライン](https://www.street-academy.com/guideline))。Posh の創業者は「まず取引を握る必要がある」と述べる ([Fortune](https://fortune.com/2026/03/19/exclusive-posh-lands-37m-series-b-what-are-we-doing-tonight-problem/))。

**前提条件・失敗条件**:[推測] 名簿を主催者に渡すと主催者が外で再集客できる迂回のリスクがあるため、決済・チケット・連絡手段を握る設計と組み合わせて採用される。決済を握らないモデル(Meetup は会費を主催者が外で集める)は迂回を防げない。

### O-M4 競合の変化を使った移行キャンペーン

**実施しているサービス**:Ticket Tailor、Luma、Posh、Eventbrite(win-back)、競合ブログ各社。

**根拠・数値**:Ticket Tailor は 2026-04-23 のブログで、Eventbrite 買収後の値上げ・サポート低下・データ共有リスクを予測し、Eventbrite との併用(dual-platforming)を勧めた。同社は料金ページで Eventbrite 同等プラン比の年 £990 の節約を試算する ([Ticket Tailor 料金](https://www.tickettailor.com/pricing))。Luma は比較ページで Alo・NBA・Stripe の移行事例を自社発信する ([Luma vs Eventbrite](https://help.luma.com/p/luma-vs-eventbrite))。Posh は 2026-06 に、ナイトライフ・コメディ等の主催者の移行が加速していると述べる ([Posh](https://posh.vip/university/post/switching-from-eventbrite-to-posh) [自社主張])。Eventbrite 自身も 2024年 Q2 の win-back で 14万枚超の有料チケットを戻したと説明する ([決算コール](https://www.marketbeat.com/earnings/reports/2024-8-8-eventbrite-inc-stock))。

**前提条件・失敗条件**:[事実] 買収後の値上げは競合ブログの予測にとどまり、公式発表は確認できていない。Luma の比較ページは Eventbrite の手数料内訳の合計が合わない箇所を含む。[推測] Eventbrite の発見経由の発券が 30%超という開示は、発見面に価値を置く主催者が乗り換えにくい理由になりうる。

### O-M5 アンバサダー・紹介報酬・プロモーター制度

**実施しているサービス**:Posh、Partiful、Luma、Zeffy、Fever、Pie、Eventbrite。

**根拠・数値**:Posh の Organizer Referral は、紹介した新規主催者のイベントで Posh が受け取る手数料の 10%を 12か月間、月初に PayPal で支払い、紹介者は参加者でもよく、過去 1年に紹介者が合計「$25万超」を得たと同社が主張する ([Posh affiliate](https://university.posh.vip/university/post/posh-affiliate-program)、[Posh サポート](https://support.posh.vip/en/articles/12611504-getting-started-with-organizer-referrals) [自社主張])。対象は新規主催者に限り、Stripe 連携が必須である。Posh の Kickback はプロモーターへの報酬を主催者が設定し(小規模公演 10〜15%、継続イベント 10〜20%、売りにくい大型 15〜25%が自社の目安)、Posh が報酬額の 20%を取る ([Kickback ガイド](https://posh.vip/university/post/a-guide-to-kickback-at-posh))。Zeffy のアフィリエイトは紹介経由のチップ純額の 30%(決済手数料控除後)を支払う ([Zeffy Affiliates](https://www.zeffy.com/home/affiliates))。Partiful は Campus Growth Manager の求人で、学生・学生団体・会場への働きかけと launch week を職務に挙げる ([Resumegeni](https://resumegeni.com/jobs/campus-growth-manager-us-spring-2026-partiful-f02c13c7d2) [要約])。Luma は 2024年に City Leads を募集した ([LinkedIn](https://www.linkedin.com/posts/vpontis_hi-were-seeing-a-lot-of-growth-with-luma-activity-7167977701897682945-Mkmg) [要約])が、創業者は 2025-01 に営業・提携をしないと書いており、位置づけは不明である。Pie Creators Club は RSVP 経由で新規アカウントを連れてきたホストに支払う ([MediaPost](https://www.mediapost.com/publications/article/416426/can-pie-cure-loneliness-new-cmo-believes-it-can.html))。Eventbrite の B2B アフィリエイトは、$8程度の成果報酬の掲載と「公開プログラムはない」という記述が不一致である [要確認]。

**前提条件・失敗条件**:[推測] 報酬を主催者の売上から払う設計は粗利が薄いと回らず、自己紹介・架空主催者の不正対策が要る。紹介経由の主催者比率はどのサービスも公開していない [不明]。

### O-M6 参加者から主催者への転換導線

**実施しているサービス**:Eventbrite、Meetup、Posh、Luma、Partiful。

**根拠・数値**:Eventbrite の都市ページには「Create Events」「Sell Tickets Online」が常設され ([Eventbrite NY ページ](https://www.eventbrite.com/d/ny--new-york/events/))、Meetup のホームには「Start a new group」が複数ある ([Meetup](https://www.meetup.com/))。FirstMark(Posh の投資家)は「主催者の 2人に 1人は最初は参加者だった」と記す ([FirstMark](https://firstmark.com/story/the-main-event-posh-raises-22m-series-a-from-firstmark-and-goodwater-to-become-shopify-for-events/) [投資家主張])。Luma は、ゲストが後にホストになる連鎖を創業者が語ったとされるが、インタビュー本文は取得できていない ([One Year Wiser](https://www.readoneyearwiser.com/p/luma-and-victor-pontis) [要約])。

**前提条件・失敗条件**:[事実] Luma・Partiful・Eventbrite のいずれも転換率は非公開である [不明]。[推測] 参加者が「自分でも主催できる」と思う動機(友人グループの幹事役、既存コミュニティ)がある層にしか効かず、主催の負担(決済・運営)が重いほど転換は低い。

### O-M7 会場・店舗・コミュニティ運営者への BD

**実施しているサービス**:Meetup、Eventbrite、Timeleft、222、Platinumlist、Fever、트레바리、Airbnb、Peatix、オミカレ。

**根拠・数値**:Meetup は初期に会場から課金して集客を送り、成立したグループの会員が提携会場 3つから投票する方式だった ([Wikipedia](https://en.wikipedia.org/wiki/Meetup))。Timeleft は店に対価を払わず、フィラデルフィアの店のオーナーは Timeleft 側から OpenTable で予約が入り、自分から連絡したことはないと述べるが、注文しない参加者が多いと店が提携終了を申し出る ([Inquirer](https://www.inquirer.com/food/timeleft-review-philadelphia-group-dining-20241022.html)、[Timeleft ヘルプ](https://help.timeleft.com/hc/en-150/articles/14236028247836-Partnering-with-Timeleft-Restaurants-Bars) [要約])。222 は会場がパートナー料を払う ([SF Gazetteer](https://sf.gazetteer.co/pay-to-play))。트레바리 は創業初期に縁のない分野の専門家を電話・訪問で粘り強く説得してクラブ長に迎えた ([이투데이](https://www.etoday.co.kr/news/view/1611867))。Fever は F1・FC Barcelona・Primavera Sound などと戦略提携し、セルフ登録の料金表を持たず営業が入口である ([MBW](https://musicbusinessworldwide.com/dice-owner-fever-raises-250m-led-by-eqt-in-what-it-calls-the-largest-ever-round-for-a-live-entertainment-tech-company)、[Fever Business](https://business.feverup.com/))。

**前提条件・失敗条件**:[推測] 店舗側の営業フックは、新規客(OpenTable の自社主張 78%)、前払いによる収益確定、閑散時間帯の充填である。BD の成果(会場数、会場経由の主催者数)は公開されていない [不明]。

### O-M8 ミッション型ブランディング(mission-driven positioning)

**実施しているサービス**:Humanitix、HelloAsso、Zeffy、Ticket Tailor、Peatix、Meetup。

**根拠・数値**:Humanitix は手数料の純利益の 100%を慈善に回し、豪では Public Benevolent Institution、米国では 501(c)(3)の法人格を持ち、Google.org $1M(2018)や Atlassian Foundation $1.2M の支援を受けた([Wikipedia](https://en.wikipedia.org/wiki/Humanitix))。[推測] 手数料の水準(4%+$0.99)は競合と大差なく、差別化は料金ではなくブランドと信頼にある([Humanitix 料金](https://www.humanitix.com/pricing))。HelloAsso は協会向けに完全無料を掲げ、2022-11 に€15Mを調達した ([Carenews 2022](https://www.carenews.com/carenews-pro/news/helloasso-leve-15-millions-pour-renforcer-son-impact-aupres-des-associations))。Ticket Tailor は B Corp(2022-05)で、登録チャリティの手数料を 50%割り引く ([Ticket Tailor](https://www.tickettailor.com/en-us/our-story))。Peatix は Tokyo Pride に 3年連続でブースを出している ([PR TIMES](https://prtimes.jp/main/html/rd/p/000000077.000058728.html))。

**前提条件・失敗条件**:[推測] 社会的使命は法人形態と税制に支えられており、日本での転用には法人形態の確認が要る(ノートの示唆)。購入者の行動への影響を示す数値は確認できていない [不明]。

### O-M9 教育コンテンツ・事例露出(education / case studies)

**実施しているサービス**:Luma、Partiful、Posh、Doorkeeper、こくちーず、EventRegist。

**根拠・数値**:Luma の「How to Promote Your Event」は、過去ゲストの招待、共同ホストへの共有、ポスター・QR、早割、UTM 付きリンクを勧める ([Luma ヘルプ](https://help.luma.com/p/promote-your-event))。Partiful は「次のイベントをすぐ公開する」などを助言し ([Partiful ブログ](https://partiful.com/blog/post/heres-how-to-actually-grow-your-audience))、Doorkeeper は導入事例 3件と主催者ストーリー 14本を載せる ([Doorkeeper](https://www.doorkeeper.jp/organizer-stories))。Eventbrite は「プレミアムなマーケティングツールを使ったイベントは販売チケットが 63%多い」と述べるが因果は不明である ([Eventbrite ブログ 2023-03](https://www.eventbrite.com/blog/?p=395362) [自社主張])。

**前提条件・失敗条件**:[事実] 教育コンテンツの定量効果は、いずれのサービスも公開していない。[推測] 集客スキルのない主催者が多い市場では、ガイドだけでは供給は増えず、発見面や代行が要る。

### O-M10 セルフサービスと営業の二層運用

**実施しているサービス**:Eventbrite、Fever、DICE、Peatix、EventRegist、Luma、Zeffy、Posh。

**根拠・数値**:Eventbrite はセルフサービスで裾野を取り、営業は大型・高頻度の主催者に向け、2025年 Q1 に「セルフ登録チャネルの再活性化」を近い目標に掲げた ([Q1 2025 決算コール](https://www.marketbeat.com/earnings/reports/2025-5-8-eventbrite-inc-stock))。Peatix は法人向け集客サービス(7万円〜)で利用実績 1,300社超を訴求し ([Peatix 法人向け](https://services.peatix.com/selltickets))、EventRegist は企業・大学・自治体への直販で Basic+ を 10万円+税とする ([EventRegist](https://info.eventregist.com/))。Luma は営業を行わない。Zeffy の求人票は、月 1,000から 2年で月 10,000の新規 NPO という目標を掲げる(目標であり実績ではない)([Growth Talent](https://www.growthtalent.org/companies/zeffy) [要約])。

**前提条件・失敗条件**:[推測] 自己登録が裾野を、営業が収益の集中する上位層を担う。営業は人手がかかり、小規模・低頻度のコミュニティ型には合いにくい(Fever のマーケ手数料型の評価)。

### O-M11 主催者の収益化を見せる・収益を分配する

**実施しているサービス**:문토、트레바리、Posh、Luma、Eatwith。

**根拠・数値**:문토は 2023年に有料モイムの精算を受けた会員 1,952人、年間 9,500万ウォンを稼いだ会員の事例を露出した([Unicorn Factory](https://www.unicornfactory.co.kr/article/2023122915330372380))。트레바리のパートナーは活動費が最終売上のシェアで、1シーズン(4か月)単位に支給され、会員→パートナー→クラブ長の昇格経路を持つ。「함께 만드는 클럽」の活動費は 40万ウォン+会費免除で最低 65万ウォン相当である([트레바리 パートナー募集](https://trevari.co.kr/blog/show?id=322f8983-07d9-43ae-b238-694fd28ddb03)、[クラブ長募集](https://trevari.co.kr/blog/show?id=68043966-3600-4eca-8bd1-83b3d50c8c62&from=curationbanner))。Posh は中位のプロモーターで月 $1,500〜$5,000という収入目安を自社記事に載せるが、独立検証はない ([Posh](https://posh.vip/university/post/how-to-become-paid-event-promoter) [自社主張])。Eatwith は新規ホストに目標価格の少なくとも 25%引きでの開始を指導する ([Eatwith ヘルプ](https://intercom.help/eatwith/en/articles/4118435-pricing-your-experiences))。

**前提条件・失敗条件**:[推測] 材料費と準備時間を含めたホストの採算が薄いと継続しない。リーダー報酬を売上に連動させるぶん、プラットフォームの利益は薄くなる(트레바리は 7年連続の赤字と報じられる)。

## コールドスタート戦略の比較:ツール先行・マーケットプレイス先行・都市/コミュニティ seeding

| 型 | 代表例 | 最初の供給のつくり方 | 強み | 弱み・失敗条件 |
|---|---|---|---|---|
| ツール先行(コミュニティ持ち込み) | Eventbrite、Luma、Partiful、Posh | 主催者が自己登録し既存コミュニティを持ち込む。Eventbrite は 2017年に 95%超が自己登録。Luma は 1人のヨガ講師の Zoom ページ、Posh は NYU・Columbia の学生パーティーから | 初期コストが低く再現しやすい。ゲストが製品に触れる=ツール自体が広告 | ツールの価値が小さいと乗り換えられる。集客力のない新規主催者が増えると別の仕組みが要る [推測] |
| マーケットプレイス/キュレーション先行 | DICE、Fever | 人手で供給を選別・営業。DICE は約 100公演を手選びして同時販売を 250以内に抑え、提携・審査制を取る。Fever は営業・戦略提携と自社制作 | 需要側の信頼を先に作り、少数の主催者へ「売れる」体験を保証 | 都市ごとの運営・調達コストが残る。DICE は 2025年に Fever に統合 |
| 都市・コミュニティ seeding | Meetup、Luma(Tech Weeks)、트레바리、Timeleft、Humanitix | 既存の塊(会場、政治キャンペーン、都市のイベント週間、専門家)を取り込む。中央カレンダーで多数の主催者を束ねる | 一度に多数の供給を得られ、地域内の密度が出る | 人手がかかり再現コストが高い。密度が閾値を割ると縮小(Timeleft の 325都市→200都市台) |
| 既存イベントの集約 | AllEvents | Web 上のソースからイベントを集約(取得方法の詳細は不明) | コールドスタートを回避できる | 無断掲載・情報の鮮度が信頼リスク(苦情の事実関係は未確認)[要確認] |
| 自社供給・人手運営 | Fever Originals、Dinner Lab | 自社で企画・調達。Candlelight は地元音楽家のネットワークで複製し 100都市超(2023報道) | 供給を自社で握る | Dinner Lab は固定費で 2016-04 に閉鎖。Fever は資本($250M)と IP が前提 |
| 親会社の基盤・ID | 당근、楽天チケット mini、LIVEPOCKET(KDDI)、パスマーケット、District | 既存の会員・決済基盤に載せる | 参加者側の初期基盤を借りられる | 基盤があっても終了する(パスマーケット、Festa) |

[事実] ツール先行の 4社(Eventbrite、Luma、Partiful、Posh)は、供給側が手元の既存コミュニティを持ち込むことで最初の密度を作っている。Luma は 2020年にヨガ講師 1人の Zoom ページから始まり ([ognotes](https://ognotes.substack.com/p/luma-the-tiny-wedge-that-quietly) [二次])、Posh の初期供給の仕込み方を説明した一次情報は見つからなかった。理論面では、Andrew Chen の「原子ネットワーク」は単独で自立できる最小のネットワークを指し、Uber の SF 7×7 マイルなどが例とされる ([Lenny's Newsletter](https://www.lennysnewsletter.com/p/atomic-network))。Chris Dixon の「Come for the tool, stay for the network」は、ツールが初期の臨界量を作りネットワークが長期の価値を生むと説く ([cdixon.org](https://cdixon.org/2015/01/31/come-for-the-tool-stay-for-the-network/))。TechCrunch の反論は、初期プロダクトにソーシャル機能が含まれないと後からネットワークを作りにくいと論じる ([TechCrunch 2016](https://techcrunch.com/2016/12/01/come-for-the-tool-stay-for-the-network-reconsidered/) [要約])。[推測] イベント領域では、ゲストが製品に触れること自体がソーシャルな露出になる点が、この反論への答えになっている。難しい側(hard side。この助言は [Indie Hackers](https://www.indiehackers.com/post/how-to-kickstart-a-marketplace-lessons-learned-from-andrew-chens-book-the-cold-start-problem-b0fdf81f6b) の二次要約による)は、継続して開催する主催者である可能性が高く、Eventbrite の売上集中と整合する。

## 失敗・撤退事例からの教訓

**Eventbrite の無料イベント手数料(2023〜2024)。** 25人超の無料イベントにも主催者手数料を課した結果、経営陣が 2024年 Q2 に獲得・維持の阻害と在庫・チケット量への不当に大きな影響を認め、2024-09-04 に撤回した。2025年ガイダンスで約$20Mの逆風、有料クリエイターは 2024年 -7%、有料チケットは 2024年 -10%、2025年 -6%である ([Q2 2024 決算コール](https://www.marketbeat.com/earnings/reports/2024-8-8-eventbrite-inc-stock)、[10-K FY2025](https://www.sec.gov/Archives/edgar/data/1475115/000147511526000005/eb-20251231.htm))。教訓は、無料枠が主催者の入口であり、触ると在庫が減って発見面の価値も下がる点にある。

**Meetup の課金設計(2019〜2026)。** 2019年10月に米国の 2州で、主催者は月$23.99(または 6か月$98.94)、参加者は RSVP ごとに$2とする試験を行い、一部の主催者が Kommunity や gettogether.community への移行を表明した ([WP Tavern](https://wptavern.com/meetup-com-introduces-rsvp-fees-for-members-wordpress-meetup-groups-unaffected-by-pricing-changes))。2024年の値上げ後は、NJHN が 2024-12 にグループを閉鎖した個別事例が出て(会員の実質活動は十数人)([NJHN](https://njhn.org/?p=4361) [要約])、OWASP は 2026-01-31 付で廃止した。WordPress コミュニティは Meetup の非効率とロックインを指摘して GatherPress への移行を検討している ([WordPress Community Team](https://make.wordpress.org/community/2026/01/28/2026-big-picture-goals-our-focus-on-meetups/))。競合の Group.app は「長年の主催者で 80%以上の値上げ」と主張するが、根拠は提示されていない [競合発信]。公式は値上げの理由に、コミュニケーション機能と統合プラットフォーム・バグ修正を挙げる ([Meetup ヘルプ](https://help.meetup.com/hc/en-us/articles/30923029605133))。

**Dinner Lab(2016年に閉鎖)。** 閉鎖発表は 2016-04-14 で、2018年ではない。会員制の覆面ポップアップ・ディナーで 31都市・約$9.1Mを調達しながら、毎回の食材・スタッフ・会場・規制対応が固定コストとなり、参加者データを店に売る構想も機能せず、追加調達に失敗した [要約] ([TechCrunch](https://techcrunch.com/?p=1307899)、[Harvard D3](https://d3.harvard.edu/platform-digit/submission/how-dinner-labs-attempt-to-crowdsource-restaurant-concepts-got-roasted/index.html))。**Hopin(2021〜2024)** は、2021年8月に評価額$78億となったが、「explore」タブの掲載が 2020年11月の 15,000件超から 2022年4月に 500件未満へ落ち、2023年8月にイベント事業を売却した ([Sifted](https://sifted.eu/articles/hopin-sells-off-its-original-events-platform) [報道・要約])。[推測] パンデミック需要の消滅で供給側の利用が一斉に減った。

**基盤があっても終わる事例。** Yahoo!パスマーケットは終了したとみられ、당근 は買収した Festa を「選択と集中」で 2025年1月に終了した ([머니투데이](https://www.mt.co.kr/future/2025/03/28/2025032814160551016))。**価格表示と手数料の不満。** Posh は手数料が競合の比較表で高い部類(10%+$0.99、[競合発信])で、表示を巡る訴訟を$120万で和解する見込みと伝えられる ([All About Lawyer](https://allaboutlawyer.com/1200000-posh-group-deceptive-ticket-fee-class-action-settlement/) [要約])。**買収後の方針転換。** Appfigures は、Bending Spoons の買収後に人員削減・値上げ・ユーザーの不満というパターンがあると分析する ([Appfigures](https://appfigures.com/resources/insights/the-company-squeezing-money-from-apps-you-used-to-love/amp))。[推測] 所有者の変更は、代替サービスに主催者が移る契機になる。

## Shokujii への示唆(推測)

以下は調査ノートの事実に基づく推測であり、優先度や工数は断定しない。

1. 幹事への手数料・月額は避け、無料で開催できる枠を保つ選択肢が、Eventbrite の 2023年の失敗と Meetup の離脱から示唆される。収益を参加者のメニュー注文に寄せる場合も、注文額への手数料率の見え方は、手数料への反発(Zeffy の初期値の不満、Posh の訴訟)を踏まえて設計する価値がある。
2. 幹事に参加者名簿と連絡手段を渡すことは獲得の訴求になる一方で、迂回の入り口にもなる。注文・決済・当日の厨房共有をプラットフォーム内に置き、名簿の閲覧権限を Luma の Tech Weeks のように段階化する案が考えられる。
3. 売上が高頻度の少数に集中する(Eventbrite)ことから、定例開催の幹事(複製、次回の即公開、フォロー・メンバー化、Doorkeeper の自動メンバー化に近い仕組み)への機能を厚くする案がある。ストアカの「再受講は低率」の二層設計は、幹事が自分の仲間を連れてくるモデルと相性がよいと考えられる。
4. 参加者から幹事への導線(参加確認画面・参加後ページ)は、Eventbrite の目論見書が「参加者としての利用経験」を獲得経路に挙げる点から検証する価値が高い。転換率の公開値がないため、自社で計測する前提になる。
5. 店舗側の獲得は、SevenRooms の事前選択と厨房共有、Tock の前払い、OpenTable の初来店客(自社主張 78%)が営業フックの先行例である。Timeleft では注文しない参加者が多いと店が離脱するため、最低注文や客単価の担保を設計に含める必要がある。店の審査を重くするほど供給の増加は遅くなる点(Airbnb、Eatwith)も踏まえる。
6. 既存ツール(こくちーず・Peatix・LINE・スプレッドシート)からの移行は、CSV 取り込みやイベント複製で負担を下げる案がある。TECH PLAY が API を公開した背景(複数サービスへの二重登録)は、連携・取り込みが主催者の摩擦を下げることを示す。Eventbrite・Meetup・connpass の変更を乗り換えの契機に使った前例がある(Ticket Tailor、Luma、Posh)。
7. 紹介・アンバサダー制度は、Posh(新規主催者のみ、手数料の 10%を 12か月)や Zeffy(チップ純額の 30%)の型がある。Shokujii では、幹事を紹介した人や店舗を対象にする案が考えられるが、原資、返金時の扱い、不正対策、法務の確認が要る。
8. 供給は「1エリア×少数の店舗×定例の幹事」を最小単位に作る(Luma の Tech Weeks、Dice の手選び、Trevari の専門家の説得に近い)。自治体・企業との共催(オミカレ)や、地域の食を支える使命(Humanitix、HelloAsso、Zeffy)は入口になりうるが、後者は法人形態・税制の確認が前提になる。

## 未確認・留意点

- ゲスト→主催者の転換率、リピート主催率、紹介経由の主催者比率、無料→有料の転換率、BD の成果(会場数)は、いずれのサービスも公開しておらず確認できなかった。教育コンテンツ、共同主催、API・連携の獲得への寄与も定量値がない。
- スパム・低品質イベントの発生率と対策の一次情報、GDPR が獲得施策に与えた影響を示す一次情報は見つからなかった。
- Eventbrite の B2B アフィリエイトの公式条件は不一致で、Luma の City Leads の運用上の位置づけは不明である。Luma の Eventbrite 比較ページは自社に有利で、数値の内訳が合わない箇所がある。Eventbrite 買収後の値上げは競合ブログの予測であり、公式発表は確認できていない。
- Eventbrite の「13%/60%」は第三者書き起こし経由で公式とは未照合である。Humanitix の寄付累計、Zeffy の NPO 数、Posh の累計調達額、Fever の手数料、DICE の手数料(競合が 10〜15%、8.5%+2.5%と不一致)は確定できない。
- Peatix の主催者向けセミナー・アンバサダー制度、Fever のアンバサダープログラム(ページ 403)の条件、TIGET・ZAIKO の手数料は未確認である。Splash・Lemonade・Geneva・Kickoff は調べられていない。문토・프립の最新手数料は公式の一次情報を取得できていない。
- Posh のクラスアクション和解の最終承認結果、Meetup の「主催者課金後に活動が 95%落ちた」とする検索要約(取得した本文には記述なし)は確認できず、採用していない。Luma は動画生成の Luma AI(2025-11 に $9億調達)とは別の会社である。
