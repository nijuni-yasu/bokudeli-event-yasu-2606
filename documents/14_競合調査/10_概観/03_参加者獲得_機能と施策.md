# 参加者獲得:機能と施策

> 調査日: 2026-10-11 / 調査範囲: 世界のイベント告知・集客・RSVP・チケッティング・コミュニティ系サービス(約45サービス、7観点で並行調査)。
> 関連: [README](../00_README.md) / [サービス概観](./01_サービス概観.md) / [グロースストーリー](./02_グロースストーリー.md) / [参加者獲得](./03_参加者獲得_機能と施策.md) / [主催者獲得](./04_主催者獲得_機能と施策.md)
> 数値は [事実] / [推測] と信頼度タグ(自社主張・競合発信・要約・要確認)付き。出典間で食い違う数値は併記している。

イベント告知・チケッティング・コミュニティ系サービスが、参加者(来場者・RSVP する人)をどう獲得しているかを、「機能(プロダクトに実装されたもの)」と「施策(マーケティング・BD・価格・コミュニティ運営)」に分けて整理した(調査時点 2026-10-11)。結論は三つである。第一に、参加者の入口は「共有(招待リンク)」「発見(検索・フィード・推薦)」「継続(フォロー・購読・メンバー化)」の三経路に分かれ、ツール型(Luma、Partiful)は共有、マーケットプレイス型(Eventbrite、DICE、Fever)は発見に重心がある。第二に、効果の数値が公開されているのは発見面(SEO・推薦)にほぼ限られ、紹介・リマインド・ゲスト→主催者の転換などの効果は、どのサービスも定量値を公開していない。第三に、食事社交の失敗例(Dinner Lab、Timeleft の過剰拡大)は、参加者を集める技術よりも、地域の参加者密度と1回あたりの固定費が成否を分けることを示す。

**読み方**:各項目の「根拠・数値」は調査ノートで出典を確認した [事実] で、「前提条件・失敗条件」の多くは [推測] である(事実の場合はその旨を付す)。[自社主張] は企業自身の数値、[競合発信] は競合のブログ等、[要約] は検索結果の要約のみで原文未確認、[要確認] は資料間で食い違うか原典未確認を表す。数値が食い違う場合は併記し、一方を採用しない。

## 三つの入口:共有・発見・継続のどこに重心があるか

Eventbrite は 2022年実績で「発券の 30%超が Eventbrite の発見(マーケットプレイス・アプリ・ニュースレター)経由で過去最高」と公表した ([Eventbrite ブログ 2023-03](https://www.eventbrite.com/blog/?p=395362) [自社開示])。裏を返せば残りの約 70%は主催者自身の集客(SNS・メール・直リンク等)であり、その内訳は開示されていない。競合の TicketSignup は大半が主催者の自己集客だと主張するが、これは競合視点の推測である ([TicketSignup](https://info.ticketsignup.io/founders-corner-eventbrites-misguided-marketplace-strategy) [競合発信])。一方、Luma の創業者 Victor Pontis は「ほぼ完全に口コミ」「営業・デモ・提携は小さなチームを保つためにやらない」と述べ ([How Luma Works](https://pont.is/p/how-luma-works))、Partiful の CEO も成長は口コミとネットワーク効果で広告ではないと述べる ([TBPN Digest 2025-10](https://www.tbpndigest.com/story/2025-10-31/shreya-murthy-on-partiful-building-the-social-layer-for-gen-z-events-and-the-future-of-offline-connection))。[推測] ツール型では主催者が自分のコミュニティに送るリンクが参加者の主入口で、発見面は後から足される。以下のカタログは、この前提の上で各機能・施策を整理する。

## 機能カタログ:プロダクトに実装された10の仕組み

### F-1 アカウント不要のリンク登録(guest RSVP / frictionless registration)

**実施しているサービス**:Luma(名前とメールのみ、ログイン不要)、Partiful(アプリ・アカウント不要だが認証済み電話番号が必要)、Doorkeeper(メールのみ)、Evite(ゲストは Evite アカウント不要 [要約])、Apple Invites(RSVP は誰でも無料)。

**根拠・数値**:Luma の確認メールにはカレンダー招待が自動で入り、対面イベントのリマインドは 1日前と 1時間前が既定である ([Luma ヘルプ](https://help.luma.com/p/event-registration-process))。Partiful はリンクを SMS・Instagram DM・WhatsApp で共有できる ([Wikipedia](https://en.wikipedia.org/wiki/Partiful))。登録摩擦を下げた効果の定量値は公開されていない [不明]。

**前提条件・失敗条件**:[事実] 反対側の例として、Peatix は参加者がログインして申し込む必要があり離脱要因になりうるという指摘がある [二次・検索要約]。[事実・二次] Partiful は認証が電話番号のみで、ホストはゲストの返信テキストを Partiful ページ上でしか読めないという使い勝手の指摘がある(2024-06 更新のレビュー、古い可能性)([party.pro](https://party.pro/partiful/))。[推測] 決済を伴う場合は、本人確認や審査(Accupass の有料イベント審査など)との両立が必要になる。

### F-2 都市×カテゴリの発見面と SEO・構造化データ(city hub / schema.org Event)

**実施しているサービス**:Eventbrite、AllEvents、Meetup、Sympla、Doorkeeper、TECH PLAY、こくちーず。

**根拠・数値**:Eventbrite のニューヨーク都市ページは、パンくず、近隣リンク、複数カルーセル、「Going fast / Almost full / Just added」のステータスバッジ、約 18のランドマークリンク、8問の FAQ、「Promoted」枠を備える ([Eventbrite NY ページ](https://www.eventbrite.com/d/ny--new-york/events/))。Eventbrite は 2015年から schema.org の Event 構造化データを導入し、Google の事例は、検索経由のトラフィックの前年比成長が約 100%上乗せされたと報告するが、同時期に複数の SEO 施策があり原因は切り分けられないと注記している ([Google Search Central 事例](https://developers.google.com/search/case-studies/eventbrite-case-study))。AllEvents の東京ページはカテゴリ別件数、日付別ページ、Moments from Events を持つ ([AllEvents Tokyo](https://allevents.in/tokyo))。

**前提条件・失敗条件**:[事実] Eventbrite の 10-K は、トラフィックが主に Google の自然検索に依存し、アルゴリズム変更や AI 対話型の発見が影響しうると明記する ([10-K FY2025](https://www.sec.gov/Archives/edgar/data/1475115/000147511526000005/eb-20251231.htm))。Google のイベント構造化データの公式対応言語・地域に日本・日本語は記載がなく、マークアップしても表示は保証されない ([Google Search Central](https://developers.google.com/search/docs/appearance/structured-data/event))。[推測] ページの中身が薄いと評価されず、公開イベントの量(供給密度)が前提になる。

### F-3 パーソナライズ推薦・ダイジェスト・プッシュ/メール(recommendation / digest)

**実施しているサービス**:Eventbrite(Discover タブ、It-Lists)、Meta(Local タブの週次ダイジェスト、テスト)、DICE(Spotify・Apple Music 連携)、Xceed(ML 推薦)、Skiddle(プッシュ・SMS)、Peatix・こくちーず(おすすめイベントメール)、connpass(開催前日メール)、Luma(キュレーション型の Discover)と Partiful(手作業のキュレーション)。

**根拠・数値**:Eventbrite は、ML 推薦等でディスカバリー経由のチケット販売が前年比 +10%(2024年 Q4)、アプリ経由の有料チケットが +11%、アプリユーザーは Web より購入確率が 3倍(2025年 Q1)と述べる ([Q4 2024 株主レター](https://www.sec.gov/Archives/edgar/data/1475115/000147511525000025/q4shareholderletterfinal.htm)、[Q1 2025 決算コール](https://www.marketbeat.com/earnings/reports/2025-5-8-eventbrite-inc-stock)) [自社主張]。DICE の Discovery が販売の約 41%を生むという主張は検索要約のみである [要確認]。connpass の創業者は「ある勉強会で 8〜9割の参加者が通知メールを見て参加」と語った [二次] ([CodeZine](https://codezine.jp/article/detail/9824))。Partiful の Discover は担当者が手作業でキュレーションする ([Marketing Brew](https://www.marketingbrew.com/stories/2026/03/09/partiful-marketing-strategy-organic-mentions-the-pitt))。

**前提条件・失敗条件**:[推測] 推薦はユーザーの履歴・位置・ソーシャルグラフに依存し、供給量が少ない市場では推薦できる件数が足りない。Meta の Local タブは「テスト」段階で成果は公表されていない ([Meta](https://about.fb.com/news/2024/10/facebook-local-tab-messenger-communities-ai/amp/))。

### F-4 友達・ソーシャルグラフの可視化(who's going / contact sync)

**実施しているサービス**:Eventbrite(連絡先同期で友人の参加イベントを表示)、Posh(ソーシャルなゲストリスト、友人の動きに基づくフィード)、Partiful(ゲスト一覧、友人のイベントフィード)、connpass(友達が公開・参加したときの通知)、Pie。

**根拠・数値**:Posh の CEO は「グループチャットは解決済みで、難しいのは会いたい 10〜20人との再会」と述べ、フィードを主軸に移している ([Fortune](https://fortune.com/2026/03/19/exclusive-posh-lands-37m-series-b-what-are-we-doing-tonight-problem/))。Pie は 2025年12月に「つながりの参加予定が見えるフィード」へ変更し、アプリ滞在が 2分から 10分に増えた ([TechCrunch 2026-08](https://techcrunch.com/?p=3156057))。Eventbrite の連絡先同期は 2025-03 のアプリ刷新に含まれる ([プレスリリース](https://www.silicon.co.uk/press-release/get-into-it-eventbrites-reimagined-app-makes-discovering-your-next-favorite-live-experience-as-enjoyable-as-being-there))。

**前提条件・失敗条件**:[推測] 連絡先・友達グラフの取り込みは同意と個人情報の扱いを伴い、初期のように友達が少ない段階では機能しない。[事実] Meta は 2018-04 に Events API を新規開発者へ閉鎖し、第三者が Facebook 上のイベントを取得できなくなった ([Facebook for Developers](https://developers.facebook.com/blog/post/2018/04/04/facebook-api-platform-product-changes/))。外部ソーシャルグラフへの依存は一方的に断たれうる。

### F-5 フォロー・カレンダー購読・自動メンバー化(follow / subscribe)

**実施しているサービス**:Luma(Calendars のフォロー・購読)、Peatix(参加でフォロワーになる)、Doorkeeper(申込者が自動でコミュニティメンバーになる)、connpass(グループメンバーへ開催通知)、TECH PLAY(グループのフォロー)、RA(主催者フォロワーへの新イベント通知)。

**根拠・数値**:Peatix のフォロー導入は 2014-07-17 で、申込と同時にフォローを促す仕組みを含む ([THE BRIDGE](https://thebridge.jp/2014/07/peatix-new-feature))。2026-07-31 にはグループページに「コンテンツ」タブを追加し、公開時にフォロワーへ自動通知する ([PR TIMES](https://prtimes.jp/main/html/rd/p/000000078.000058728.html))。Doorkeeper は申込者を終了後でもメンバー化し、開催通知を届ける ([Doorkeeper](https://www.doorkeeper.jp/how-it-works))。参加率・リピート率への効果の数値は確認できず [不明]。

**前提条件・失敗条件**:[推測] 購読の価値は定期開催の主催者に偏り、単発イベントでは小さい。[事実] Eventbrite は 2025年 Q3 に「有料クリエイターの 13%が有料チケットの約 60%」と述べており ([決算コール](https://www.marketbeat.com/earnings/reports/2025-11-6-eventbrite-inc-stock) [要約])、リピートする主催者に参加者を紐づける設計の重みを示す。

### F-6 カレンダー追加・リマインド・当日導線(calendar / reminder / wallet)

**実施しているサービス**:Luma(iCal 同期、確認メールにカレンダー招待、Apple Wallet パス)、Meetup(RSVP 確認メールが Google カレンダーへ自動追加、他は .ics)、こくちーず(カレンダー書き出し 2019-10)、connpass(カレンダー同期、前日リマインド)、Eventbrite(Apple/Google Wallet 保存、2026-04)、DICE(アプリ内 QR)、Platinumlist(動的 QR の SafeTickets)、Partiful(SMS 更新)。

**根拠・数値**:Meetup の更新情報に、確認メールのカレンダー自動追加が記載されている ([Meetup Product Updates](https://product.meetup.com/date/2025/12))。Platinumlist は毎分数回更新されオフラインでも動く動的 QR(SafeTickets)を案内する ([2024 Year in Review](https://platinumlist.net/for-organisers/guide/platinumlists-2024-year-in-review/))。リマインドによる出席率の改善値は確認できていない [不明]。

**前提条件・失敗条件**:[事実] SevenRooms は、メニューを事前選択していないゲストへ自動リマインドを送り、厨房へ集計を共有する ([SevenRooms](https://sevenrooms.com/platform/events-experiences/))。[推測] 食事会では、リマインドは「人数確定の締切」「メニュー確定の締切」と連動してはじめて意味を持つ。

### F-7 紹介リンク・共有ツール・紹介報酬(referral / share)

**実施しているサービス**:Luma(Event Referrals)、Posh(Kickback)、Peatix(2014年のソーシャル拡散プログラム)、Meta(Instagram フォロワー・SMS・メール招待)、Eventbrite(ソーシャル共有)。

**根拠・数値**:Luma は登録直後にゲストへ友人招待リンクの共有を促し、主催者が Insights で「誰が人を連れてきたか」を見られる。報酬はない ([Event Referrals](https://help.luma.com/p/event-referrals))。Posh の Kickback は購入者が紹介リンクを得て、報酬は主催者の設定でチケット代から差し引かれ、Posh が報酬額の 20%を取る。返金・チャージバックは紹介者の負担である ([Kickback ガイド](https://posh.vip/university/post/a-guide-to-kickback-at-posh))。Peatix は 2014年に、SNS で拡散した参加者へチケット 10%割引を出した ([THE BRIDGE](https://thebridge.jp/2014/07/peatix-new-feature))。Meta は非ユーザーも SMS・メールの招待から RSVP できる。Eventbrite 関連の二次記事は、Facebook シェア 1回あたり約$4.15の追加売上と記すが、時点不明で第三者検証もない ([7x7](https://www.7x7.com/amp/co-founder-julia-hartz-on-her-role-as-the-operator-at-eventbrite-1786195744) [二次])。

**前提条件・失敗条件**:[事実] 紹介経由の比率・k-factor はいずれのサービスも公開していない [不明]。[推測] イベントでは招待を送る人が主催者側の一部に限られ、全ユーザー平均の k は低い。報酬原資を主催者売上に置く設計は、主催者の粗利が薄いと回らず、不正(自己紹介)対策も要る。

### F-8 ウェイトリスト・残席表示・ステータスバッジ(waitlist / scarcity)

**実施しているサービス**:DICE(売り切れ時のウェイトリスト、同時販売公演数の上限)、Fever(公開前ウェイトリスト)、Eventbrite(ステータスバッジ)、Luma(残席・早割の推奨)、Doorkeeper・connpass(補欠繰り上がり)。

**根拠・数値**:Fever は Alice in Wonderland 体験で公開前に 12,000人超がウェイトリスト登録し、$60/人の 6月分が数日で完売した ([TechCrunch 2018](https://techcrunch.com/2018/07/05/fever-gets-20m-to-delight-more-hipsters-with-a-b-tested-madhatters-gt-parties))。DICE は返却された券を先着で配分する ([Wikipedia: Dice](https://en.wikipedia.org/wiki/Dice_(ticketing_company)))。DICE のブログにある「200人規模の公演に 600人のウェイトリストなら追加 3公演」という例は検索要約のみである [要確認]。希少性施策の転換効果の数値は確認できていない [不明]。

**前提条件・失敗条件**:[推測] 需要が供給を上回る状況でのみ働き、供給過多の市場で残席を煽ると信頼を損なう。

### F-9 総額表示(all-in pricing)

**実施しているサービス**:DICE(upfront all-in pricing)、RA(単一価格を推奨)、Skiddle(「Booking Fee Free」表示を主催者が選べる)、Posh(2026-04 から総額表示とする競合の記述)。

**根拠・数値**:RA のサポート記事は、手数料を別行表示せず単一価格にした方が購入転換が 3〜5%高い自社テスト結果を示し、手数料込み価格を推奨する ([RA サポート](https://support.ra.co/article/40-booking-fees) [要約])。Posh は手数料表示を巡る米国カリフォルニアのクラスアクションを$120万で和解する見込みと伝えられるが、最終承認の結果は未確認である ([All About Lawyer](https://allaboutlawyer.com/1200000-posh-group-deceptive-ticket-fee-class-action-settlement/) [要約])。

**前提条件・失敗条件**:[推測] 手数料の見せ方は転換率に影響し、不透明な表示は法的リスクにもなる。

### F-10 同席マッチング・安全・欠席対策(食事特化。matching / no-show policy)

**実施しているサービス**:Timeleft、222、Pie、盲盒饭局(整点薯条/薯岛)、Bumble Plans。

**根拠・数値**:Timeleft は約 50問の性格テストで卓を編成し、年齢差 5〜7歳、性別・内向外向の混合を設計する ([Timeleft アルゴリズム解説](https://timeleft.com/post/timeleft-algorithm-the-maestro-of-your-dinners/))。無断欠席料は 1か月サブスク料金の 35%(米国を除く)で、同卓の 2人以上が欠席を報告すると記録される ([Timeleft ヘルプ](https://help.timeleft.com/hc/en-150/articles/25012703925148-What-Is-the-No-Show-Penalty-Fee) [要約])。新フォーマットの導入でユーザーの月平均利用は 1.4回から 2.2回に増えた ([Substack](https://timfrin.substack.com/p/inside-timelefts-journey-to-connecting) [自社側発言])。222 は無断欠席で退会とする ([SF Gazetteer](https://sf.gazetteer.co/pay-to-play))。盲盒饭局は 27問のアンケートで 5人を組み、薯岛は通報の多い利用者の除外・未成年の登録拒否・緊急相談ボタンを置く ([澎湃](https://m.thepaper.cn/newsDetail_forward_33717234))。

**前提条件・失敗条件**:[事実] 利用者からは「欠席の罰則が弱い」「卓が 3人になった」という報告があり ([Tasting Table](https://www.tastingtable.com/1859085/dinner-parties-with-strangers-timeleft/))、質問が個人的すぎる、マッチが「臨床的」という指摘もある ([VICE](https://www.vice.com/en/article/timeleft-friend-finding-platform-review/))。[推測] 席数が少ないほど 1人の欠席の影響が大きく、前払い(Tock・OpenTable・Resy)、罰金と評価(Timeleft)、退会(222)のいずれかで欠席を抑える必要がある。

## 施策カタログ:マーケ・BD・価格・コミュニティ運営の10施策

### M-1 口コミ・有機成長に絞る(広告・営業を持たない)

**実施しているサービス**:Luma、Partiful、Meetup(2013年時点)。

**根拠・数値**:Luma はフルタイム 6名で数百万ユーザーに達した ([Pontis](https://pont.is/p/how-luma-works))。Partiful は 2026-03 にマーケティングチーム 3名、予算は小さく、広告は出さず、TikTok の UGC 増幅やクリエイター提携を試験中と報じられた ([Marketing Brew](https://www.marketingbrew.com/stories/2026/03/09/partiful-marketing-strategy-organic-mentions-the-pitt))。Meetup は 2013年に、マーケ・PR・BD 担当を置かず広告も出さず、新入社員が近隣グループを訪ねる「Meetup crawl」を行った ([NBC](https://www.nbcnews.com/id/wbna53820139))。

**根拠・数値**:Eventbrite の 10-K は SEO・SEM・アフィリエイト・ソーシャル・メール・動画を挙げ、2025年 Q3 にパフォーマンスマーケ起点の有料注文が前期比 +28%と CEO が述べた([決算コール](https://www.marketbeat.com/earnings/reports/2025-11-6-eventbrite-inc-stock))。TikTok 提携(2024-07)は「1日 1億超のインプレッション」と自社が述べる ([Q2 2024 決算コール](https://www.marketbeat.com/earnings/reports/2024-8-8-eventbrite-inc-stock) [自社主張])。Fever の求人は ROAS 3:1 超を掲げるが目標値であり実績ではない ([Growth Talent](https://www.growthtalent.org/jobs/growth-marketing/fever/growth-marketing-associate-fever))。Fever のアフィリエイトは料率が非公開で、第三者ネットワークの記載(基本 8%、平均 6.4% 等)は食い違う [要確認]。Eatwith のアフィリエイトは 6〜10%程度とされる ([Travelpayouts](https://travelpayouts.com/en/offers/eatwith-affiliate-program) [要約])。Platinumlist はアフィリエイトプログラムの掲載を確認できたのみである。Timeleft は 2024年1月のバルセロナ以降「広告のみ・ローカルアンバサダーなし」で展開したと説明するが、別の記事は city manager の存在を示し矛盾する ([Substack](https://timfrin.substack.com/p/inside-timelefts-journey-to-connecting)、[Inquirer](https://www.inquirer.com/food/timeleft-review-philadelphia-group-dining-20241022.html))。

**前提条件・失敗条件**:[推測] 供給が薄い都市で広告を打っても予約できる枠が足りない。CAC・ROAS の実績値はどのサービスも公開していない。

### M-4 自社メディア・編集コンテンツ・PR

**実施しているサービス**:Fever(Secret London/NYC 等)、Xceed(Nightmag)、RA、TECH PLAY、Timeleft、Partiful、Meetup。

**根拠・数値**:Fever は都市ブランドの SNS・Web メディアで告知と行動データを集め、2018年に週間ユニークユーザー 1,200万超と主張した ([TechCrunch 2018](https://techcrunch.com/2018/07/05/fever-gets-20m-to-delight-more-hipsters-with-a-b-tested-madhatters-gt-parties))。Meetup は 2004年の Dean 陣営の利用でピーク時 14.3万人を取り込み、2010年に TechCrunch 5周年を機に Meetup Everywhere を発表して告知時の約 150件から 3日後に 252件、その後 352件超の開催が立った ([Wikipedia](https://en.wikipedia.org/wiki/Meetup)、[TechCrunch 2010](https://techcrunch.com/2010/05/31/techcrunch-meetups))。RA は編集コンテンツ・チャートが強みと競合の比較サイトが評価し [競合発信]、TECH PLAY はマガジン・技術ブログ・動画を持ち、Xceed は 2016年に Nightmag を立ち上げた。Partiful は HBO のドラマ「The Pitt」の台詞で言及されたが仕込みではない ([Marketing Brew](https://www.marketingbrew.com/stories/2026/03/09/partiful-marketing-strategy-organic-mentions-the-pitt))。

**前提条件・失敗条件**:[推測] 再現性が低く、プロダクトに「話題になる理由」がある場合にだけ働く。

### M-5 需要を先に作ってから供給する(Originals / 事前ウェイトリスト)

**根拠・数値**:Fever は自社データで需要を予測し、2019年にマドリードで始めた Candlelight を地元音楽家のネットワークで複製して、2023年の報道では 100都市超になった ([Calgary Journal](https://calgaryjournal.ca/2023/03/14/candlelight-concerts-light-up-the-city/))。BookMyShow のライブイベント収入は FY22 ₹24.6 Cr から FY25 ₹756 Cr に伸び ([Inc42](https://inc42.com/?p=571141))、同社は自社 IP の運営で垂直統合を進める。

**前提条件・失敗条件**:[事実] 人手で毎回調達する自社供給の Dinner Lab は 2016-04 に閉鎖した ([TechCrunch](https://techcrunch.com/?p=1307899))。Fever の都市別ローンチの具体的手順と成否率は確認できていない [不明]。

### M-6 エリア単位のローンチと密度設計(atomic network)

**実施しているサービス**:Timeleft、DICE、Fever、당근 모임、Luma(Tech Weeks)。

**根拠・数値**:Timeleft は広告で速く都市を開き、都市あたり週 50人以上を目標に深さを作り、325都市まで広げた後、小都市で同じ約 10人と毎週会って飽きられ、200都市台に縮小した ([Substack](https://timfrin.substack.com/p/inside-timelefts-journey-to-connecting))。リスボンでは開始から 2か月余りで月 2,500人が食事した ([Timeleft ブログ](https://timeleft.com/blog/2023/09/17/timeleft-expands-to-porto-join-the-dining-revolution/))。DICE は 2014年に DJ が約 100公演を選び、同時販売を 250公演以内に抑えて始めた ([Design Week](https://www.designweek.co.uk/issues/september-2014/new-gig-ticketing-service-dice-aims-to-be-loved-by-music-fans/))。당근 は江南区中心の試験で、4週間で約 400のモイムと約 3,000人の加入を得たと発表した ([Byline Network](https://byline.network/2023/07/31-163/))。

**前提条件・失敗条件**:[推測] 都市・ジャンルの密度が閾値に満たないと、探した人が何も見つけられず離脱する。全国一律の広告では解決しにくい。

### M-7 会員制・サブスクによる参加コミットメント

**実施しているサービス**:트레바리、Timeleft、222、District(Eternal)。

**根拠・数値**:트레바리 は 4か月を 1シーズンとする会員制で、2020-09 に会員がコロナ前比 75%急減し、2021年・2022年に各約 28億ウォン規模の営業赤字を出した ([이데일리](https://v.daum.net/v/20250109070512262))。2025年も営業赤字が拡大し、7年連続の赤字と報じられる ([Threads](https://www.threads.com/@outstanding_crew/post/DXssSYCgWrE/) [二次])。District Pass は 3か月 ₹999 で映画チケット最大 3枚無料などを付け、先行投資で District は赤字である ([MediaNama](https://www.medianama.com/2026/01/223-eternal-doubling-down-district-despite-rising-losses/))。

**前提条件・失敗条件**:[推測] 会費が前払いのコミットメントを生む一方、外部ショックで一斉に解約され、リーダー報酬を売上に連動させるぶんプラットフォームの利益が薄い。

### M-8 キャンペーン・割引・ポイント

**実施しているサービス**:Peatix、ストアカ、Timeleft、こくちーず。

**根拠・数値**:ストアカは LINE ログインでの新規登録時に 100pt を付与する ([ストアカ](https://www.street-academy.com/))。Timeleft は新規向けに €5 割引コードを案内する ([Timeleft ブログ](https://timeleft.com/post/back-to-basics-timeleft-launches-its-unique-dinners-in-paris/))。こくちーずは毎年 11月に翌年カレンダーを 200名にプレゼントし、会員数のマイルストーンでもキャンペーンを行う ([こくちーず お知らせ](https://www.kokuchpro.com/group/members/news/))。Peatix の 2014年の施策は上記 F-7 の通りである。効果の定量値は確認できていない [不明]。

**前提条件・失敗条件**:[推測] 割引は短期の登録を増やしても、供給(開催数・店)が薄ければ定着しない。

### M-9 開催タイミングの設計とデータの提示

**実施しているサービス**:teket、Partiful。

**根拠・数値**:teket は「開催 20日前〜当日に約 50%が購入」という自社データを示し、告知の山を作る、訪問が多い時間帯(平日夕方・休日正午)に告知する、複数広告の CV 率を比べる、と主催者に助言する ([ASCII](https://ascii.jp/elem/000/004/253/4253597/))。Partiful では Halloween が 1ユーザーあたり 6件超のイベントが作られる最大のピークである ([TBPN Digest](https://www.tbpndigest.com/story/2025-10-31/shreya-murthy-on-partiful-building-the-social-layer-for-gen-z-events-and-the-future-of-offline-connection))。

**前提条件・失敗条件**:[推測] 直前購入の傾向はジャンルで異なる(teket は小〜中規模のライブ・演劇)。食事会では人数確定の締切が先に来るため、同じ形では使えない可能性がある。

**実施しているサービス**:オミカレ、Posh、Partiful、ソウル市(公的運営)。

**根拠・数値**:オミカレは金沢市「恋フェス 2026」(参加費 1,000円、男女各 50名の抽選)や鳥取砂丘のイベント(参加 102名、成立 43組)を自治体と共催し、自治体が信頼性・会場、オミカレが集客を担う ([PR TIMES](https://prtimes.jp/main/html/rd/p/000000259.000020019.html)、[PR TIMES](https://prtimes.jp/main/html/rd/p/000000270.000020019.html))。ソウル市の「幸せな食卓」は 2022年から全 25区で運営され、参加者の約 95%が満足と答えた ([ヘラルド経済](https://biz.heraldcorp.com/article/10494801))。Posh と Partiful は学生アンバサダー/Campus Growth の職を募集している [要約・求人票経由] ([startup.jobs](https://startup.jobs/campus-growth-ambassador-posh-8113513))。FirstMark(Posh の投資家)は NYC の大学生の 10人に 1人が Posh のイベントを予約したと主張する [自社・投資家主張] ([FirstMark](https://firstmark.com/story/the-main-event-posh-raises-22m-series-a-from-firstmark-and-goodwater-to-become-shopify-for-events/))。

**前提条件・失敗条件**:[推測] 自治体共催は抽選などで需給を調整できる反面、個別の運営コストが高く、都市ごとに再現する必要がある。

効果の数値が公開されているものは、ほぼ発見面と推薦に限られ、しかも大半が自社開示である。下表は、根拠の質を出典の性質で仕分けた。

## 失敗・撤退事例からの教訓

**密度の不足は広告では埋まらない。** Timeleft は 2024年に 320都市超へ広げ、2025年に 200都市台へ縮小した。自己分析では、小都市は参加密度が足りず同じ顔ぶれに飽きられた。目標を「都市あたり週 50人以上」に置き、パリを深さの基準にした ([Substack](https://timfrin.substack.com/p/inside-timelefts-journey-to-connecting))。**固定費は参加者数と無関係に発生する。** Dinner Lab(閉鎖は 2016年)は毎回の食材・スタッフ・会場・規制対応を新規に用意し、会費が賄えず、一部の都市では 6週間に 1回しか招待が来なかった ([Harvard D3](https://d3.harvard.edu/platform-digit/submission/how-dinner-labs-attempt-to-crowdsource-restaurant-concepts-got-roasted/index.html)、[Failory](https://failory.com/cemetery/dinner-lab))。

**パンデミック需要は一過性である。** Hopin は 2021年8月に評価額$78億となり、「explore」タブのイベント掲載は 2020年11月の 15,000件超から 2022年4月に 500件未満へ落ち、2023年8月にイベント事業を RingCentral へ売却した ([Sifted](https://sifted.eu/articles/hopin-sells-off-its-original-events-platform)、[TechCrunch](https://techcrunch.com/2023/08/02/hopin-ringcentral)) [報道・要約]。트레바리 の会員 75%減も同じ構図である。**大手の基盤があっても終わる。** Yahoo!パスマーケットは Yahoo! JAPAN の ID 基盤と 3.24%の手数料を持ちながら終了し、당근 は買収した B2B イベント SaaS「Festa」を 2025年1月に終了した ([Web担](https://webtan.impress.co.jp/n/2014/06/06/17630)、[머니투데이](https://www.mt.co.kr/future/2025/03/28/2025032814160551016))。[推測] 単体のイベント基盤は、既存の日常アプリの導線に載せない限り参加者を集めにくい。

**参加者への課金は反発を招く。** Meetup は 2019年10月に、米国の 2州で、主催者の月額を下げる代わりに参加者へ RSVP ごとに$2を課す試験を行い、会員・主催者の反発を受けて一部の主催者が他サービスへの移行を表明した ([WP Tavern](https://wptavern.com/meetup-com-introduces-rsvp-fees-for-members-wordpress-meetup-groups-unaffected-by-pricing-changes))。**外部依存は一方的に断たれる。** Meta は 2018年に Events API を閉じ、Eventbrite は検索とアプリストアへの依存を 10-K でリスクとして明記する。**表示の不透明さは訴訟になる。** Posh の手数料表示を巡るクラスアクションは前述の通りである。

## Shokujii への示唆(推測)

以下は調査ノートの事実に基づく推測であり、優先度や工数は断定しない。

1. 参加者の入口は、アカウント不要のリンク参加(Luma・Partiful・Doorkeeper の型)を基本形にし、日本では LINE での共有を主経路とする案が考えられる。注文・決済を伴うため、本人確認や認証をどこまで求めるかは別の論点になる。
2. メニュー注文を含めた総額を最初から見せる設計は、RA(転換 +3〜5% [要約])、DICE の総額表示と整合し、手数料表示への不信(Posh の訴訟)も避けやすい。
3. カレンダー自動追加と、注文・人数確定の締切に連動したリマインドは、Luma・Meetup の仕組みに加え、SevenRooms の「未選択者への自動リマインド」と同じ思想で、食事会に固有の価値を持ちうる。
4. 欠席・人数不足への対策は、事前の注文確定(前払いに近い)を軸に、Timeleft の欠席料(1か月サブスクの 35%)や 222 の退会のような罰則を併用する案がある。少人数の卓では 1人の欠席の影響が大きい。
5. 密度は東京・大阪などエリアとジャンルを絞って作る(Timeleft の教訓)。評価指標は総登録数ではなく、エリア別の開催成立率や、店あたり月間開催数が妥当と考えられる。
6. 紹介は、まず Luma 型の「誰が連れてきたか」の可視化から検証し、Posh 型の報酬(原資・返金時の扱い・決済・法務)は後から判断する段階案が考えられる。
7. 発見面は、初期は手作業のキュレーション(Partiful 型)と、自治体・企業との共催(オミカレ型、ソウル市の公的食卓)を入口にする案がある。SEO は日本・日本語が Google の公式対応リストにないため、効果を過大に見込まず別途検証する。
8. 知らない人同士の会食(同席マッチング)を扱う場合は、通報・審査・未成年の排除など安全設計(薯岛の例)を機能として最初から決めておく必要がある。

## 未確認・留意点

- 紹介経由比率、k-factor、リマインドの出席率改善、カレンダー購読の効果、無料→有料の転換率、ゲスト→主催者の転換率は、どのサービスも公開しておらず確認できなかった。上表の数値は自社開示が中心で、第三者検証がない。
- Eventbrite の「13%/60%」は第三者の書き起こしの要約で、公式の書き起こしとは未照合である。Eventbrite の発見経由比率は 2023年以降の最新値が確認できていない。
- Timeleft の数値は資料間で食い違う(参加者 15万人/月と約 6万人/月、都市数 200台と 285・300・320、調達 $2M〜$7M、日付の異なる複数の報道)。ヘルプページは取得できず検索要約によるため、欠席料(35%)は [要約] である。
- Posh のユーザー数(600万/800万)、Fever の国数・リーチ表記、Partiful の MAU(推計)は定義が揃わない。Facebook Events の利用者数、Instagram の最新イベント機能、Nextdoor は調べられていない。Reddit・Product Hunt・App Store レビューの本文は取得できていない。
- 日本の参加者向け施策(Peatix のメルマガ・LINE・ポイント)、イベントサービス側の LINE 公式アカウント標準連携、食事会主催者の使用ツールの実態調査は確認できなかった。Luma の「Wrapped」型の振り返り機能も確認できていない(検索に出た Wrapped は別会社だった)。
- DICE の Discovery 41%、OpenTable の 78%、RA の 3〜5%、Platinumlist の 600%は、検索要約または自社主張に基づく。
