## 1. Peatix

### Takeaway
日本最大級の汎用イベント/チケッティング。参加者獲得は「検索・おすすめ・フォロー・アプリ」と「有料のおすすめメール/掲載(クイックプラン)」の二本立て、主催者獲得は「無料掲載・無料イベント手数料0・4.9%+99円/枚」「1,300 社超の法人実績」「提携・協賛を使った PR」。2026 年はコンテンツ紹介ページ・銀行振込・請求書払いなど主催者側の収益/運営機能を継続拡張している。

## 2. Doorkeeper

### Takeaway
IT 勉強会・セミナー・コミュニティ運営寄りの「有料プラン(月額)型」。主催者を月額で課金する設計(2016 年に転換)で、参加者が自動的にコミュニティメンバーになる点が売り。公式ニュースは 2023-02-22 を最後に止まっており、2025〜2026 年の料金改定・提携の公式発表は確認できない。

IT 勉強会の事実上の標準(自称 利用者約 90 万人、月 1,500 件超)。「参加者より主催者に良い機能」を設計思想に基本無料で拡大してきたが、**2026 年 11 月に有料プランを開始し、無料のグループメッセージにも月 7,000 通の上限を設ける**と発表(2026-08-05)。

- ビープラウドは 2006 年設立、自社サービスに PyQ/TRACERY/connpass。[二次] — [検索要約(開示資料)](https://www2.jpx.co.jp/disc/52500/140120250711512099.pdf)
- 収益モデル: 現状は基本利用料なし(事前決済は PayPal のみで手数料は PayPal のもの、connpass は取らない)。フッターに広告掲載。[事実] — [connpass/about](https://connpass.com/about/)(取得。更新時期は不明)

## 18. 日本市場特有の事情と獲得施策への影響

### Takeaway
(a) LINE 1 億ユーザー、(b) IT 勉強会文化の強さと複数サービス併用、(c) コンビニ/銀行振込/後払いを含む決済の多様性、(d) 無料文化と有料化への反発リスク、(e) コロナ後のオンライン→オフライン回帰、の 5 点が主催者/参加者獲得の設計を規定している。

### Cited Findings
- 勉強会の複数サービス併用: TECH PLAY API 公開の背景として「主催者は複数のプラットフォームへ同じ情報を個別に登録・更新している」と明記(2026-08-05)。[事実] — [PR TIMES](https://prtimes.jp/main/html/rd/p/000000015.000183857.html)。2018 年時点で connpass/Doorkeeper の API から情報を取り込む TECH PLAY や、複数サイト横断通知サービス(Study Mail)が存在。[二次] — [クラスメソッド](https://dev.classmethod.jp/articles/study-site/)
- 使い分けの目安: connpass=IT 勉強会の継続運営、Doorkeeper=メンバー化によるリピーター獲得、TECH PLAY=技術系イベント告知とグループ、いずれも基本無料(Doorkeeper は月額)。[事実] — [linestep 2026-06-02](https://linestep.jp/?p=68732)
- 決済の多様性: コンビニ/ATM(Peatix 購入者 220 円・こくちーず購入者 220 円・Doorkeeper の Stripe コンビニ(2023-01))、銀行振込(Peatix 2025-08・Doorkeeper)、PayPal(connpass/こくちーず/Peatix)、後払い(LivePocket あと払い)、請求書払い(Peatix 集客サービス 2025-07、TIGET 請求書カード払い)、PayPay: 取得範囲では確認できず。[事実] — 各節の出典
- 有料化の潮流: Doorkeeper(2016)、connpass(2026-11 有料プラン+メッセージ上限)、Meetup(2024 プラン改定)。[事実] — 各節
- コロナ後の動き: ぴあ総研は 2025 年の公演回数が 2019 年以来の 10 万回台に回復と報告([KAI-YOU](https://kai-you.net/article/95702))。オンライン機能は 2020 年に Doorkeeper(オンライン対応、2020-06-22)・こくちーず(オンラインイベント機能、2020-06-01、オンデマンド 2023-03)・ZAIKO/teket が整備。2026 年も TIGET が「bizmee 配信」(オンライン相談/レッスン販売、2026-06-24)を追加するなどオンラインの継続需要も残る。[事実] — [Doorkeeper news](https://www.doorkeeper.jp/news), [こくちーず](https://www.kokuchpro.com/group/members/news/), [tiget.net](https://tiget.net/)

### Inferences
- [推測] 主催者の「無料で始め、有料化時に課金」「複数サービス併用」を前提に、API/インポートで二重入力を減らす設計が主催者獲得に効く。決済は「コンビニ/銀行振込+カード」を持たないと取りこぼす可能性がある。

### Gaps
- オンライン/オフライン比率の日本のコミュニティイベント統計(Peatix 等の公式データ)。

## 21. 示唆(推測)— Shokujii 向けの短いメモ

1. [推測] 日本の主催者獲得は「無料で作れる」「手数料は低め(4.8〜5%台+固定額)」「リピーターを囲える(フォロー/メンバー化)」の 3 点が共通項。固定 99 円は低単価で効き、幹事型イベントでは固定費の見せ方に配慮が要る。
2. [推測] ストアカの「自己集客 10%/プラットフォーム集客 30%/再訪 10%」は、幹事が自分の仲間を連れてくるモデルと相性が良い。幹事経由の参加者は低率、プラットフォームが新規を連れてくる場合のみ高率、という二層設計は主催者獲得に使える。
3. [推測] 複数プラットフォーム二重登録の負担(TECH PLAY API の背景)は、Peatix/こくちーず/connpass の既存イベントを取り込む/連携する機能が主催者の乗り換え障壁を下げる可能性を示す。
4. [推測] LINE は日本の最大到達チャネルだが、ストアカのように外部連絡先を禁じる例もある。Shokujii は LINE 通知・LINE ログインの導入が参加者獲得に効く一方、規約設計(外部誘導の扱い)を決める必要がある。
5. [推測] Passmarket の終了、connpass の有料化は、「大手でも無料前提の主催者基盤は維持が難しい」ことを示す。無料イベントの扱い(完全無料か、一定数まで無料か)の設計は初期から決めておく価値がある。
6. [推測] 自治体×オミカレのように「信頼性と会場は公的、集客は民間」の共催が成立している。食事会でも飲食店・自治体・企業との共催が主催者(幹事)獲得の入口になりうる。
7. [推測] 食事会の汎用ツール(こくちーず/Peatix)は「申込+決済」までで、メニュー選択・人数確定・店連携は別手段という隙間が示唆されるが、これは実在調査(未取得)による裏付けが必要。
