# 飲食店を口説きやすいポイント（機能・訴求の整理と周辺アイデア）

Instagram の DM で飲食店オーナーに連絡し、**一言で良さを感じてもらい、「これができるなら導入してみたい」と思ってもらう**ための材料整理。営業資料の中心に置く一言、DM 文例、機能の優先順位、周辺アイデアをまとめる。

- 作成日: 2026-10-07
- 対象: shokujii の追加機能（貸切・誕生日会・テーマ交流会・コミュニティ）を飲食店に提案する場面
- 関連資料: [00 サービス機能一覧 統合サマリ](../市場・競合調査/00_サービス機能一覧_統合サマリ.md)、[01 事業性評価](../市場・競合調査/01_事業性評価_一体型コミュニティの成否と対策.md)、[03 誕生日開催サービス 総合](../誕生日開催/03_誕生日開催サービス_総合.md)、[02 街コン市場と店コン検討](../市場・競合調査/02_街コン市場と店コン検討.md)
- **根拠の強さ**: 【確認】公開資料で確認 / 【二次】業界記事・当事者の主張 / 【仕様書】shokujii の仕様書に記載（**実装状況は未確認**）/ 【推論】本書の推測。点数や優先度は**主観の仮置き**で、DM テスト（§9）の結果で置き換える

## 1. 結論（資料の中心に置く一言）

### 1.1 刺さりやすさの順に並べた一言（案）

| 順位 | 一言（飲食店向け） | 刺さる理由 | 注意 |
| :-- | :-- | :-- | :-- |
| 1 | **「お客様が、お客様を連れてくる。広告費0円の貸切予約。」** | 店にとって最もつらい「新規集客のコスト」を、常連が肩代わりするという構図が一言で伝わる | 「必ず売上が増える」とは書かない（景品表示法の観点。§10） |
| 2 | **「空いている時間を、貸切の誕生日会で埋めます。0円で、成約したときだけ。」** | 閑散帯（アイドルタイム）の悩みと、費用リスクのなさが同時に伝わる | 手数料条件の確定が前提（§8） |
| 3 | **「人数が足りなければ自動で中止、お金は事前にいただくので、ドタキャンも赤字もゼロ。」** | 無断キャンセル・貸切の赤字という具体的な恐れを消せる | 「ゼロ」は断定しすぎないよう「防ぎます」等に調整 |
| 4 | **「Instagram のプロフィールに貼るだけ。貸切予約ページを無料で作ります。」** | 店が既に使っている Instagram に直結し、作業が増えない（DM 営業との相性も良い） | ページ作成の代行コストを要確認 |
| 5 | **「アレルギー・ヴィーガン・ハラールも、参加者全員分を事前に共有。」** | 事故への不安を減らし、他にない独自価値になる | 売上の訴求にはならない。補助の一言として使う |

**推奨の組み合わせ**: 一言は 1 位または 2 位、安心材料は 3 位と「0 円・成約時のみ」を添える。DM で出会いや誕生日会の需要を断定せず、**質問形式**にして返信を取りにいく（§7）。

### 1.2 なぜこの一言か（要点）

1. 飲食店の関心は、**売上が増える・手間が増えない・損をしない**の 3 つに集約される（【推論】）。機能の豊富さ（掲示板、チャット、サブスク）は DM の一言では響きにくい。
2. 既存の議論で最も有力だった「**会員主催の貸切**」「**誕生日会**」は、店から見れば**「お客様が人を連れて来て、事前に代金も払って貸切にしてくれる」**だけの話になる。この見え方に翻訳する。
3. コミュニティ・チャット・サブスクは、**営業の入口では出さない**。導入後に店が欲しがったら提案する（§5、§6）。

## 2. 飲食店が動く条件（意思決定のフィルター）

オーナーは DM を読んでから、次の問いを無意識に確認する（【推論】。DM の運用担当は経営者・店長が 54.6% とする調査がある【二次】。個店では本人が直接読む前提で設計する）。

| # | 問い | 満たすために必要なこと |
| :-- | :-- | :-- |
| Q1 | 売上になるのか | 閑散帯・平日・新規客に効くと一言で分かる |
| Q2 | お金はかかるのか（先に払うのか） | 初期費用 0・月額 0・成約時のみ（§8 で条件を確定） |
| Q3 | 手間は増えるのか | ページ作成を代行、当日の進行シートを自動生成 |
| Q4 | 損をしないか（赤字貸切・ドタキャン） | 最低人数・最低消費額・事前決済・自動中止 |
| Q5 | 店の雰囲気・ブランドを壊さないか | 店が承認・拒否できる、出会い系にしない |
| Q6 | 実績はあるのか | 実績ゼロの課題への対策が必要（§8） |
| Q7 | ホットペッパー・LINE・既存の予約で足りないのか | 「それらにない価値」を一言で示す |

**根拠となる飲食店の悩み**

- 閑散時間帯は固定費の負担が重く赤字になりやすいとされる【二次】。
- グルメサイトは、リピーターにつなげにくい・販促コストが高いという声がある。Google の利用率がトップになる傾向も指摘されている【二次】。
- 無断キャンセルは業界課題で、2018 年に業界団体・経産省・消費者庁などが対策レポートを公表。キャンセル料の目安はコースで 100%、席のみで平均客単価の 50%。事前決済の導入で月 100 件の無断キャンセルがほぼゼロになった焼肉店の事例がある【確認／二次】。被害総額は情報源で数字が異なるため本書では採用しない。
- LINE レストランプラス（2026-06 開始、1 年目は実質 0 円）が、配信・CRM の領域で無料に近い選択肢になった【確認】。**「配信・顧客管理」では口説かない**。

## 5. 「口説きやすさ」の優先順位

### 5.1 採点基準（各 1〜3 点、合計 18 点。**主観の仮置き**）

| 軸 | 3 点 | 1 点 |
| :-- | :-- | :-- |
| ① 一言で伝わる | 一文で意味が分かる | 説明が必要 |
| ② 売上直結 | 売上に直接つながる | 間接的 |
| ③ 店の手間が小さい | ほぼ手間なし | 運用負担が大きい |
| ④ リスクが小さい | 損失・ブランド毀損の恐れが小さい | 恐れが大きい |
| ⑤ すぐ始められる | 既存機能（仕様書あり）で近い | 新規開発が大きい |
| ⑥ 競合と違う | 他にない | 同様のものが多い |

### 5.3 読み取れること

1. **上位は「貸切で売上」「ドタキャン・赤字なし」「ゼロ手間・ゼロ費用」の 3 本柱**。この 3 つで DM と資料の中心を作る。

## 7. 訴求と DM の設計

### 7.1 DM の基本方針

1. **短く、1 通 1 メッセージ、質問で終わる**。返信のハードルを下げる（個店は本人が読む前提）。
2. **店の投稿を見たことを一言入れる**（定型文の大量送信に見えないように）。
3. 資料はリンクではなく**「1 枚の画像」**を添付すると見てもらいやすい（【推論】）。
4. **使わない言葉**: 出会い、街コン、婚活、コミュニティ、SaaS、プラットフォーム、システム。
5. **断定しない**: 「必ず売上が増える」「ドタキャンゼロ」は避け、「防ぎます」「減らします」を使う。

### 7.2 DM 文例（要確定箇所は〔 〕で示す）

**A. 閑散帯の貸切（標準）**

> はじめまして、shokujii の〇〇と申します。〇〇さんの投稿を拝見し、ご連絡しました。
> 平日の空席を、お客様の誕生日会・貸切で埋める仕組みを作っています。初期費用・月額は 0 円、成約したときだけ費用がかかります〔条件を確定〕。人数が足りなければ自動で中止になり、代金は事前にいただくので、赤字貸切やドタキャンは防げます。
> 貸切にしても大丈夫な曜日・時間帯はありますか？ あれば、予約ページを無料で作ります。

**B. 常連が連れてくる（集客の悩み向け）**

> はじめまして、shokujii の〇〇です。〇〇さんの常連さんが、友達を連れて貸切パーティーを開けるサービスを作っています。広告費はかからず、人数が集まった分だけ予約が確定します。
> 「誕生日や記念日にお店を使いたい」というご相談、普段ありますか？

**C. 食の制約（ヴィーガン・ハラール対応店向け）**

> はじめまして、shokujii の〇〇です。〇〇さんのヴィーガン対応のメニューを拝見しました。アレルギーや食の制約がある方の貸切・交流会を、参加者全員分の情報を事前に共有できる形で集めるサービスです。貸切の募集、まずはお試しでやってみませんか？

### 7.3 資料（1 枚）の構成案

| 位置 | 内容 |
| :-- | :-- |
| 最上段（中心） | **一言**（§1.1 の 1 位または 2 位）と、店名入りの貸切ページの見本画像 |
| 上段 | 3 つの安心: ①0 円・成約時のみ ②人数不足は自動中止・事前決済 ③ページ作成は代行 |
| 中段 | 4 ステップ: お客様が主催 → 友達が事前に決済・メニュー選択 → 人数確定 → 当日はお任せ（進行シート付き） |
| 下段 | こんな店に: 平日の空きがある／貸切の相談が時々ある／Instagram を運用している／食の制約対応 |
| 最下段 | 質問型の CTA（「貸切できる曜日はありますか？」）と、連絡先 |

### 7.4 送る相手の優先順位

| 優先 | 店のタイプ | 当てる一言 | 理由 |
| :-- | :-- | :-- | :-- |
| 1 | 貸切を既に受けている個人店・バー | B、A | 貸切の経験があり、手間と効果を理解している |
| 2 | 平日・昼の客数が少ない個人店 | A | 閑散帯の悩みが明確 |
| 3 | ヴィーガン・ハラール・アレルギー対応を打ち出す店 | C | 差別化が効き、競合が薄い |
| 4 | 誕生日・サプライズ対応を既に打ち出す店 | A、B | 需要が確認しやすい |
| 5 | 既存の shokujii 利用店 | 追加機能として案内 | 信頼がある |
| 後回し | チェーン、予約が常に埋まる人気店 | — | 意思決定が遅い、空席の悩みが小さい |

### 想定される反論と回答

| 反論 | 回答の方向 |
| :-- | :-- |
| 「忙しくて新しいことは無理」 | ページ作成は代行。当日の進行シートも自動生成 |
| 「手数料が高いのでは」 | 成約時のみ。条件は〔確定した内容〕。ホットペッパー等の掲載料と比べて説明できる形にしておく |
| 「ブランドが心配」 | 承認制。お断りはいつでも可能。出会い系にはしない |
| 「実績はあるの？」 | 創業メンバー店として〔特典〕。最初の 1 件は一緒に集める |
| 「ホットペッパー・LINE で足りている」 | 貸切・事前決済・友達の招待は別の機能。併用できる |

| 「アレルギーの事故が怖い」 | 参加者の情報を事前に全員分共有。店が受けられない場合は断れる |
| 「未成年の飲酒は？」 | 年齢確認を必須にし、酒類は成人のみ |

## 9. DM 営業のテスト設計

| 項目 | 内容（仮置き） |
| :-- | :-- |
| 仮説 | 「お客様が連れてくる」「閑散帯を埋める」「ドタキャン・赤字を防ぐ」のうち、返信率が最も高いのはどれか |

- 「売上が増える」「ドタキャンゼロ」などの表現は、根拠がない断定を避ける（景品表示法の観点。専門家確認を推奨）。
- Instagram の DM 営業は、同一内容の大量送信や自動化でアカウント制限を受ける可能性がある（Instagram の規約・運用ルールは未確認。送る前に確認すること）。個人事業主・法人への営業連絡の取り扱いも、必要に応じて専門家に確認する。
- 無断キャンセルの被害総額は情報源によって数字が異なり、本書では採用していない。
- 既存機能の「仕様書あり」は実装済みを意味しない。営業で約束する前に動作を確認する。
- 店舗手数料の条件（§8 #1）は、既存の課金設計で未定義の部分を含む。営業開始前に確定する。
- 法務（資金決済法、特商法、出会い系サイト規制法、景品表示法、個人情報）は一般論で、専門家の確認を代替しない。
