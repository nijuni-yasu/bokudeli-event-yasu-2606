# 飲食店開催検討

shokujii で「飲食店で人が集まる場（貸切・誕生日会・店舗主催イベント・交流の場）」を事業として作るための、調査・評価・設計の資料群。

## 資料番号について

資料には**フォルダの並び順に 00〜07 の通し番号**を付けている。本文中の「03 §9」「05 §14」「02 の K3」といった参照は、この番号を指す（例: 「02 の K3」は 02 街コン市場と店コン検討 のリスク K3）。

## 読む順

1. **全体像**: 00 → 01（なぜ「誕生日」「店舗主催」に絞るのか）
2. **個人（会員）主催**: 03 → 04
3. **店舗主催**: 05 → 06
4. **営業**: 07（出会いイベントを検討するときは 02 も）

## 根拠の書き方

各資料は、根拠の強さを 【確認】【一次】【二次】【仕様書】【推論】 のラベルで区別している。評価点・試算・人数・価格は**仮置き**で、検証の結果で更新する。法務・税務の記述は一般論で、専門家の確認を代替しない。

## 元調査・アーカイブ

- `元調査/`: 生成 AI の調査結果の原本。各資料はここから、店名・出典のある事例だけを根拠として使っている。出典のない数字は採用していない。
- `_アーカイブ/`: 誕生日開催・店舗主催の資料を統合・分割する前の旧版。内容は現行の資料に含まれている。
