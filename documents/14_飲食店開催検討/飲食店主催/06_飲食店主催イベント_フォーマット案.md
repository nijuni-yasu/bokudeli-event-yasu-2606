# 飲食店主催イベント フォーマット案

飲食店が主催するイベントを、shokujii 上で「型（フォーマット）」として用意するための検討とブレスト。店は型を選び、日付を決めるだけで開催できる状態を目指す（[店舗主催定例イベント検討](05_店舗主催定例イベント検討.md) の L1「型のパッケージ配布」の具体化）。

- 作成日: 2026-10-08
- 根拠: `元調査/` フォルダの 3 本の調査（[ChatGPT](元調査/ChatGPT調査_飲食店主催イベントの成功事例.md)・[Claude](元調査/Claude調査_個人店イベントの成功事例.md)・[Gemini](元調査/Gemini調査_飲食店主催イベントの成功事例.md)）
- 関連資料: [店舗主催定例イベント検討](05_店舗主催定例イベント検討.md)（定例化・最小催行・チャット・レポート）／[誕生日開催サービス 総合](../誕生日開催/03_誕生日開催サービス_総合.md)／[貸切イベント案（誕生日以外）](../誕生日開催/04_貸切イベント案_誕生日以外.md)
- **根拠の強さ**: 【一次】店・主催者の公式情報、店主インタビュー／【二次】メディア・ブログ・業界記事／【推論】本書の推測。評価点・定員・価格は**仮置き**
- **調査の使い方**: 3 本のうち、**店名・出典つきで裏づけのある事例だけ**を根拠にした。出典のない成果数字（ChatGPT 調査の「+240%」「58% が再来店」など）、販促ベンダーの効果数字（トリビア業者の「+300%」など）、Gemini 調査の LTV 一般論は採用していない

## 1. 要点

1. **フォーマットは「参加条件 × テーマ × 過ごし方」の組み合わせ**で作る（§2）。A 限定会（誰が来るか）、B テーマ会（何を味わうか）、C 遊びの会（どう過ごすか）に、D 体験・共創、E コラボ、F 会員・定期、G 祝い・記念日を加えた 7 区分で整理した（§3、§4）。
2. **第 1 弾の候補は、仮置きの○を維持したうえで、裏づけの強さで並べ替えると「蔵元・ワイナリーの会」「おひとり様限定会」「新メニュー試食会」が上位**（§5）。「おふたり様限定会」「誕生月限定会」は事例が弱く、**仮説として小さく検証**する位置づけ。
3. **全フォーマット共通の土台**が成否を分ける（§6）: 募集開始日時の固定、年間スケジュールの先出し、段階的なキャンセル規定、**催行段階（パーティー／テーブル／不成立）**、撮影・行動規範の同意、アレルギー申告、開催後のレポート。国内の最も確かな一次事例（稲毛屋）は、この土台を店が自力で作っている。
4. **「組み合わせ」で数を増やせる**（§5.3）。例: 「おひとり様限定 × 蔵元の会」。1 つ作れば、参加条件を差し替えて別の型になる。
5. shokujii の既存仕様（最小催行人数・自動中止・事前決済・アルバム）で足りる部分が多いが、**催行の 3 段階化、募集開始日時の予約公開、参加条件の判定（1 名／2 名／誕生月／来店履歴）、同意チェック、売上分配**は新規（§7）。

## 2. フォーマットの考え方

### 2.1 設計軸

1 つのフォーマットは、次の軸の組み合わせとして定義する。

| 軸 | 内容 | 例 |
| :-- | :-- | :-- |
| 参加条件（誰が） | 申込できる人を絞る | 1 名のみ、2 名 1 組、当月生まれ、初来店、来店 N 回以上 |
| テーマ（何を） | 食・酒・体験の中身 | 蔵元 1 銘柄、新メニュー、ゲストシェフ、季節行事 |
| 過ごし方（どう） | 席の作り方・交流の仕掛け・遊び | 相席の大テーブル、席替え、クイズ、ボドゲ |
| 開催リズム（いつ） | 頻度・曜日・時間帯 | 毎月第○曜、隔週月曜、毎週、年 1 回 |
| 催行段階（成立条件） | パーティー／テーブル／不成立の人数 | §6.2 |
| 収益の形 | 参加費、前払い、売上分配 | 会費制、飲み放題料金のみ、ゲストと折半 |

**参加条件・テーマ・過ごし方は独立しているので、組み合わせられる**（§5.3）。

### 2.2 事例から見えた「型」の共通点（根拠の整理）

| # | 共通点 | 根拠となる事例 |
| :-- | :-- | :-- |
| 1 | 定例化して「この日は○○の日」にする | 稲毛屋（ほぼ毎月・主に火曜 19 時）【一次】、かっぱのボドゲ会（毎月）【一次】、英国パブの週 1 クイズ【二次】 |
| 2 | テーマは 1 つで分かりやすく、中身を入れ替える | 稲毛屋（1 回 1 蔵）【一次】、Brown Butter Supper Club（1 食材から物語）【二次】 |
| 3 | 閑散日・定休日・閉店後を使う | Brown Butter（休業日にレジデンシー）、gertrude's（隔週月曜）、Ma Der Lao Kitchen（月 1 の定休日の月曜）【二次】、稲毛屋（火曜）【一次】 |
| 4 | 定員は小さく、増やすときは**席ではなく回数** | 稲毛屋（人気回は第 1 部・第 2 部）【一次】、Brown Butter（上限 60 人、夜を増やす）【二次】 |
| 5 | 一人参加を前提に、交流は**仕組み**で生む | Brown Butter（約 30% が一人。大皿の取り分け）【二次】、OZmall の誕生日会（ソロ 9 割）【一次：PR】 |
| 6 | 募集ルール・キャンセル規定を公開する | 稲毛屋（2 か月前の 1 日 9 時に募集、キャンセルは 1 週間前まで）【一次】 |
| 7 | 常連向けと一般向けを分ける | 稲毛屋（土用鰻の会は一般募集しない）、かっぱ（あえて内輪）【一次】。常連が固まりすぎた例: パーラー305【一次】 |
| 8 | 開催後の続きが次回の申込を生む | Brown Butter（レシピ送付）、もしも…（写真送付）【一次・二次】、Premieres（結果報告を記事化）【一次】 |

### 2.3 フォーマットカードのひな形

shokujii に登録する 1 フォーマットの標準項目。店は、この項目が埋まった状態の型を選んで日付を入れる。

| 項目 | 内容 |
| :-- | :-- |
| 名称・一言 | 例:「蔵元の会 — 1 回 1 銘柄で、作り手と飲む夜」 |
| 区分 | A〜G |
| 参加条件 | 判定方法（申込人数、生年月日、来店履歴、会員区分） |
| 定員・催行段階 | 定員、パーティー／テーブル／不成立の人数 |
| 開催リズム | 頻度・曜日・時間帯・所要時間 |
| 料金の考え方 | 参加費、含まれるもの、原価の目安、追加注文の有無 |
| 席の作り方 | 相席の大テーブル、カウンター、ベンチ＋椅子、席替えの有無 |
| 交流の仕掛け | 自己紹介カード、アイスブレイク、遊び |
| 当日進行 | 受付〜解散のタイムテーブル（§3.2） |
| 告知素材 | タイトル、説明文、写真、募集開始日時、年間スケジュール |
| 同意・規約 | キャンセル規定、撮影同意、行動規範、アレルギー申告 |
| 開催後 | レポート、レシピ・お酒のリスト、写真、次回予告、アンケート |
| 向く業態・NG | 向く店、避ける条件 |
| 指標 | 参加人数、段階、新規比率、再参加率、売上、工数、満足度 |

### 5.3 読み取れること

1. **仮置きの○（T01・T02・T03・T06・T07）は、評価でも上位に入る。** 差が出るのは根拠で、**T06 は一次の事例が最も強く**、T02・T03・T07 は個人店の事例が見つからない**仮説**。
2. **T05 常連さん限定会は 16 点で、仮置きに○がない。** 自前の名簿で埋まり、すぐ始められる（稲毛屋の一般募集しない型）。ただし新規が入らず固定化するリスクがあり、T04・A08 とセットで考える。**第 2 弾の候補**。
3. **T08 ゲストシェフの夜は根拠が強いが、ゲスト調整の手間と謝礼で赤字リスクがある**（③・④が低い）。売上分配と最低保証の設計が済んでから。
4. **遊びの会（T10・T11）は同点で並ぶ。** 店の業態（バー・立ち飲み）が合えば、**毎週・毎月の固定曜日**で手間が少ない一方、shokujii の機能（最小催行・テーブル開催）とは噛み合いにくい。

### 5.4 第 1 弾の提案

協力店 3〜5 店、各店 3 回（[05 §14](05_店舗主催定例イベント検討.md) の検証計画と接続）。店のタイプで型を割り当てる。

| 店のタイプ | 第 1 弾の型 | 理由 |
| :-- | :-- | :-- |
| 和食・居酒屋・ワインバー（酒を揃えられる店） | **T06 蔵元・ワイナリーの会**（可能なら T01 と組み合わせ） | 根拠が最も強い。募集開始日時の固定・キャンセル規定・年間スケジュールの先出し（稲毛屋型）をそのまま実装できる |
| 小箱のバー・ビストロ・カフェ | **T01 おひとり様限定 × T07 新メニュー試食会** | 原価が低く、人数が少なくてもテーブル開催に落とせる。ソロ参加の需要も検証できる |
| 常連が多い個人店 | **T03 誕生月限定会**（＋T05 常連さん限定会） | 誕生日のファネル（個人の誕生日会への入口）を低リスクで検証できる。仮説なので、軽い演出から |
| 友人連れの来店が多い店 | **T02 おふたり様限定会** | 「友達の友達」の接点を作る検証 |

**ねらい**: (1) 根拠の強い型（T06）で「定例化の土台」が機能するかを確認、(2) 仮説の型（T01・T02・T03・T07）で需要と運営の負荷を測る、(3) 同じ土台の上で参加条件だけ差し替えて比較する。

- 常連で埋まる店は、新規が入りにくくなる（パーラー305 は方針を転換して新規客でにぎわう店に）。

- 反対に、常連限定（T05）は自前の名簿で埋まり、囲い込みに効く。**常連限定と一般募集を使い分ける**（稲毛屋）。

## 9. 未決事項

1. **第 1 弾の型の割り当て**: §5.4 の 4 つのタイプでよいか。T05（常連さん限定）を第 1 弾に入れるか。
2. **T02・T03 の位置づけ**: 事例が見つからない仮説だが、第 1 弾に含めるか（検証用）。
3. **催行段階の人数**: §6.2 の初期値でよいか。ゲストが来る T06 の不成立の扱い（ゲストへの謝礼・保証）。
4. **価格**: 新フォーマットの参加費の考え方。店の原価率との関係。
5. **店舗側の手数料**（07 の §8 #1）と、ゲストへの売上分配の負担。
6. **「出会い」要素の扱い**: T01・T02 の訴求を「交流」にとどめるか。男女別の限定会は扱わない前提でよいか（02 の K3）。
7. **キャンセル規定の法務確認**（消費者契約法 9 条 1 号。段階設計の妥当性）。
8. 既存の**最小催行人数・自動中止の実装状況**と 3 段階化の工数。

## 10. 注意事項

- 国内の個店で成果を**数字で**公開している事例は少なく、稲毛屋（公式スケジュール）以外は「満席」「行列」など定性的な記述が中心。リピート率や閑散帯の稼働率の改善を店が公表している例は確認できなかった。
- gertrude's の「通常営業の 2〜3 倍」は、ブロガーがシェフ本人から聞いた**二次情報**。
- 海外事例の多くはメディア紹介記事による二次情報。自宅発のサパークラブ（Two Economists、Solanki 氏）は厳密には店舗主催ではなく、設計の参考。
- **ChatGPT 調査の「来店 280 名（+240%）」「生産者ディナーが 5 日前に完売」「再来店 58%」「63% が来客 30% 増」などは出典が特定できず、本書では根拠に使っていない。**
- トリビア業者・販促ベンダーの効果の数字（+20〜30%、+300% など）は宣伝目的の数字として使っていない。
- 「最小催行→テーブル開催」と「誕生月の合同会」は、成功事例ではなく**推論に基づく提案**。A/B テストなどの検証が前提。
- 評価点（§5）、人数（§6.2）、価格（§6.8）は**仮置き**。
- 法務（消費者契約法、肖像権、個人情報、酒類提供、出会い関連の規制）は一般論で、専門家の確認を代替しない。
