# 街コン市場の動向と「店コン」（飲食店内の出会いイベント）サービスの検討

街コンなど出会いイベントの市場動向と集客手法を整理し、**飲食店1店舗の中で開催する出会いイベント（以下「店コン」）** を shokujii のサービスとして立ち上げる場合の可否・リスク・対策を検討する。

- 制約: 主要運営会社（リンクバル）の開示資料は取得できず（アクセス制限）、**運営会社ごとの集客チャネル別の数字は確認できていない**

## 1. 結論

| 項目 | 判断 |
| :-- | :-- |
| 街コン市場は伸びているか | **伸びているとは言えない。** 大規模街コンは縮小し、小規模・テーマ型に移行。最大手の一社（リンクバル）の直近売上は前年比 6.4% 減・営業赤字。マッチングアプリが代替している |
| 集客は SEO 中心だったか | **ポータル掲載・自社サイト（SEO）・SNS・チラシの組み合わせが定石**（【二次】）。ただし運営会社別の内訳は未確認。「地域名＋街コン」のような検索はポータル運営会社が先行している（【推論】） |
| 店コンは過去にあったか | **ある**（2012 年に 1 店舗貸切 100 人規模の「店コン」が開催された記録がある。【確認】）。現在も続いているかは未確認 |
| shokujii の店コン | **単独で出会いを主目的にするのは不利。** 「食の制約・趣味テーマ型の少人数交流会」を店の空き時間に開催する**主催システム型**なら検討の余地がある |
| 最大の論点 | (1) 男女比と参加者の質 (2) 集客の二面性（男女両方を集める） (3) 法務・安全 (4) 収益性 |
| 推奨 | **出会いを前面に出さない**。まず「テーマ交流会」として小さく検証し、需要が確認できてから恋活・婚活に寄せるか判断する |

## 2. 街コンなど出会いイベントは伸びているか

### 2.1 確認できた事実

| 指標 | 内容 | 根拠の強さ |
| :-- | :-- | :-- |
| リンクバル（街コンジャパン運営・東証上場）の業績 | 2025 年 9 月期の売上高は約 9.06 億円（前年比 6.4% 減）、営業損失約 0.89 億円、純損失約 1.97 億円。2026 年 9 月期の会社計画は売上 9.71 億円・営業利益約 200 万円 | 【確認】（決算情報サイト） |
| コロナの打撃 | 2021 年 9 月期は売上が 53.1% 減 | 【確認】（市場情報サイト） |
| 開催スタイルの変化 | 大規模（100 名以上）が減り、**男女合計 10〜50 名程度の小規模**に移行。男女比の調整、司会進行、全員と話せる保証など「出会いやすさ」を改善 | 【二次】（IBJ Matching の記事。運営側の主張） |
| 開催数 | 「誕生以降、開催数は増加し続けており衰退していない」と運営側は主張 | 【二次】（利害あり。独立した統計は確認できず） |
| マッチングアプリの台頭 | 運営会社は 2019 年の 5 社から 2026 年は 35 社に増加（前年比 25% 増）。20 代ではアプリ経験者の割合が他の婚活サービスより高い | 【確認】（東京商工リサーチ等） |
| アプリの伸び鈍化 | 世界的に、2024 年・2025 年ともマッチングアプリのインストール数・セッション数が減少 | 【確認】（Adjust） |
| 自治体の動き | 神奈川県など、自治体がオフライン恋活・婚活イベント（ボードゲーム、和文化など）を多数開催 | 【確認】（自治体公開情報） |

### 2.2 解釈（【推論】）

1. **全体としては成熟〜横ばい、大規模型は縮小。** 上場運営会社が減収・赤字であることは、街コン事業の成長性が高くないことを示唆する。ただし 1 社の業績であり、市場全体の結論にはしない。
2. **小規模化・テーマ化は店コンに追い風。** 10〜50 名規模・テーマ型は 1 店舗で完結でき、1 店舗貸切の形と整合する。
3. **アプリの鈍化はオフライン回帰の余地**を示すが、今回の調査では「オフラインに戻っている」ことを示す日本の統計は確認できなかった。自治体が熱心なのは、少子化対策としての公的支援の追い風の可能性がある。
4. **「伸びている市場に乗る」のではなく「縮小する大規模型から小規模・テーマ型へ移る流れに乗る」位置づけ。**

## 3. これまでどのように集客してきたか

### 3.1 確認できたこと（【二次】）

| 手法 | 内容 |
| :-- | :-- |
| ポータル掲載 | オミカレなどの婚活イベントポータルは、主催者が無料で情報を掲載できる。ユーザーはポータルで検索・予約する |
| 自社サイト・SEO | 「地域名＋サービス名」で検索されることを狙い、自社サイトを上位表示させる。ブログ・イベント案内の継続発信が重要とされる |
| SNS | LINE、X、Instagram、YouTube、Facebook を活用。早割・クーポンの配布 |
| チラシ | カフェ、飲食店、美容室、ネイルサロンなどに配布を依頼する（30〜40 店への営業が推奨されている） |
| 開催実績の訴求 | 実績を積んで信頼性を高める。個室ブース・一人参加限定などで参加しやすさを出す |
| 運営会社自身のプラットフォーム化 | リンクバルは「街コン開催企業」から「開催企業と参加者のプラットフォーム」に姿を変えつつあるとされる（【二次】） |

### 3.2 確認できなかったこと

- 街コンジャパン・パーティーパーティー・IBJ・オミカレの**流入元の内訳（検索・広告・アプリ・メルマガの比率）**、1 人あたりの獲得コスト。開示資料の取得に失敗し、公開データでは見つからなかった。
- したがって「SEO 中心で伸びた」とは断定できない。

### 3.3 推論（【推論】）

- 運営会社は「**ポータルに掲載して検索流入を取る＋会員のメール・アプリで再来訪させる**」二層構造を取っていると考えられる。ポータルは多数のイベントを集約するため、「地域名＋街コン」「地域名＋婚活パーティー」は強い競合が先行する領域である（要検証。検索結果の実態を後で確認する）。
- 男女の両面集客が必要なため、広告費が嵩み、**1 人あたりの獲得コストの高さが収益を圧迫**してきたと推測される。会員基盤（再来訪）を持つ会社が有利になる。

## 5. shokujii 版「店コン」の構想

### 5.1 コンセプト案

**「テーマで集まる、店の空き時間の交流会」** をつくる。出会いは目的ではなく、結果として生まれるものとして扱う。

| 要素 | 内容 |
| :-- | :-- |
| 主催者 | ① 店（空き時間の集客） ② 外部の主催者（コミュニティ運営者、趣味の幹事） ③ shokujii（直営テーマ企画） |
| 規模 | 10〜30 名程度（既存の小規模化の流れに合わせる） |
| テーマ | 食の制約（ヴィーガン、ハラール、グルテンフリー等）、趣味（ボードゲーム、読書、映画など）、年代・職種 |
| 仕組み | shokujii が予約・決済・参加者管理・アレルギー確認・男女比の調整を担う（主催システム型） |
| 参加の形 | **1 人参加と友達同士の 2〜3 人参加を併用**（R's の料金設計を参考。一人参加の心理的ハードルを下げる） |
| 食の価値 | 店が出す料理を事前に選べる（既存の事前注文機能）。食の制約に対応した料理で、参加者が安心して話せる |

### 5.2 差別化（既存の街コンに対して）

1. **食の制約・テーマで絞る**: 汎用の街コンは「異性との出会い」だけで競争する。食の制約を共有することは、初対面でも会話のきっかけになり、参加者の質も揃う（【推論】）。
2. **1 店舗ごとの小規模開催**: 大規模街コンの「店を回遊する」不便さを避ける。
3. **店の空き時間を使う**: 店は閑散帯の売上が立つ。主催システム型なので、店が運営を抱えない。
4. **既存の会員基盤**: shokujii の既存ユーザー・店の会員に直接案内できる（広告費の削減）。

## 7. うまくいかない理由と対策

優先度は「発生可能性 × 致命度」。**K1〜K5 は事業の成否を左右する。**

### K1. 男女比と参加者の質を保てない【可能性: 高 / 致命度: 高】

- **理由**: 出会いイベントの満足度は男女比と当日の運営品質で大きく変わる（【二次】）。男女どちらかが集まらないと開催できない。男性は集まりやすく女性が集まりにくい、といった偏りは出会い市場に一般的に見られる（【推論】）。一度でも男女比が崩れた、または参加者の質が低いイベントがあると、口コミで評判が落ちる。
- **失敗の形**: 開催中止の連発、サクラ（運営が用意するスタッフ）への依存、返金対応の増加。
- **対策**:
  1. **性別の定員制**（男女の定員を設定し、片方が満員でも他方が揃うまで確定しない）。最小催行人数に達しなければ自動中止＋全額返金。
  2. **テーマを絞り、参加者の層を揃える**（食の制約・趣味・年代）。性別を問わない「交流会」から始める（出会いを主目的にしない）。
  3. 友達同士の参加を許す（参加単位を 1〜3 人）。
  4. サクラは使わない（景品表示・信頼のリスク）。
  5. 当日の司会進行・席替え・自己紹介カードなどの運営ノウハウを標準化し、店のスタッフに負担をかけない。

### K2. 集客コストが高く、両面集客が成り立たない【可能性: 高 / 致命度: 高】

- **理由**: 男女両方の参加者を、開催のたびに集めなければならない。ポータルや広告に頼ると 1 人あたりの獲得コストが参加費を上回る（【推論】）。リンクバルの減収・赤字は、この構造の厳しさを示す可能性がある。「地域名＋街コン」の検索は既存の運営会社が強い（【推論】）。
- **失敗の形**: 開催するたびに集客費が赤字になり、継続できない。
- **対策**:
  1. **広告に頼らない**: shokujii の既存ユーザー、店の会員（LINE）、主催者（コミュニティ運営者）の自前の参加者を使う（主催システム型の「集客力は主催者次第」への対策）。
  2. **既存ポータルの無料掲載を活用**（オミカレなどは無料掲載が可能。【二次】）。正面の SEO 競争は避ける。
  3. **ロングテールの SEO**: 「ヴィーガン 交流会 東京」「ハラール 友達づくり」など、競合が薄い食の制約系キーワードに絞る。
  4. 参加者の紹介（友達同士割引）と再来訪（過去参加者へ次回案内）で獲得コストを下げる。
  5. **1 人あたりの獲得コストの上限を事前に定め**、超える企画は止める。

### K3. 法務・規制・安全【可能性: 中 / 致命度: 高】

- **理由**（以下は一般論で、**専門家確認が必須**）:
  - **出会い系サイト規制法**（正式名称「インターネット異性紹介事業を利用して児童を誘引する行為の規制等に関する法律」）は、インターネットで異性との交際を求める者の情報を掲載する事業を対象とする。対面の街コン自体の規制ではないが、**オンラインで異性の参加者プロフィールを掲載・マッチングする機能を設ける場合は該当しうる**（要確認）。
  - 参加費の返金・キャンセル、広告表示の適正化（景品表示法）、個人情報（特にアレルギー情報・交際希望の情報）。
  - 酒類提供の際の年齢確認（未成年の飲酒の防止）、泥酔・事故、ハラスメント・ストーカー・勧誘（マルチ商法・宗教・投資）の持ち込み。
  - 婚活事業の関連規制（結婚相手紹介サービスなどに適用される特定商取引法の類型）に該当するかの確認。単発のイベントが対象かは未確認。
- **失敗の形**: 運営開始後の規制対応、事故による店・shokujii のブランド毀損。
- **対策**:
  1. 事前に弁護士へ **(a) 出会い系サイト規制法の該当性 (b) 特商法 (c) 景品表示法 (d) 個人情報** を確認する。
  2. **オンラインで参加者プロフィールを公開しない**（匿名・当日のみの交流）。連絡先交換は当日のイベント内に限る。
  3. 本人確認（年齢確認）を必須にし、20 歳未満は参加不可・酒類提供なし。
  4. 通報・ブロック・出入り禁止の仕組みと、店・運営の対応窓口を用意。
  5. アレルギー情報は用途限定・保持期間限定。

### K4. 収益性が成立しない【可能性: 高 / 致命度: 高】

- **理由**: 参加費は 3,500〜6,000 円程度が相場（2012 年の店コンの水準。現在の相場は未確認）。参加費の大半は飲食代で店の売上になり、shokujii の取り分（手数料）は小さい。決済手数料も差し引かれる。
- **試算（仮置き。実データではない）**: 男 5,000 円 × 15 人＋女 3,500 円 × 15 人 ＝ 127,500 円。shokujii の手数料を 15% とすると約 19,000 円、決済手数料（約 3.6% 前後と仮定）約 4,600 円を引いて約 14,500 円/回。月 20 回開催しても粗利は約 29 万円。営業・運営・サポートの人件費を賄うには、開催数を大きく伸ばすか、単価を上げる必要がある。
- **対策**:
  1. **手数料率と単価の最適化**: 参加費を高めに設定（食の質を上げる）し、手数料を取りつつ店の利益も確保。
  2. **アドオン収益**（ドリンク追加、撮影、記念品など）。
  3. 主催システムとして **外部の主催者から利用料を取る**（月額または 1 回あたりの利用料）。主催者が集客して売上を持ち込む形にする。
  4. 開催数を稼ぐため、**誕生日会・歓送迎会・女子会などの別用途と共通の仕組み**にする。出会いに依存しない。
  5. 試算を実績で更新し、1 回あたりの粗利が一定額を下回る企画は停止する。

### K5. 店側の理解・ブランドリスク【可能性: 中 / 致命度: 高】

- **理由**: 店が「出会いの店」と見られたくない。トラブルで常連が離れる。本業との時間帯競合（【二次】）。ナンパ・迷惑行為への店員の対応負担。
- **対策**: 店が **開催する時間帯・テーマ・参加条件を決める**（承認制）。出会いを売りにしない「交流会」表記から始める。店の看板に影響する場合の出入り禁止権限。初期は閑散時間帯・平日・ランチの交流会に限定する。

### K6. 古い型で新規性が弱く、既存運営会社に勝てない【可能性: 中〜高 / 致命度: 中】

- **理由**: 1 店舗貸切の店コンは 2012 年から存在する。既存運営会社（IBJ など）が同じ形式を自前で開催できる。
- **対策**: **テーマ（食の制約）と主催システム（外部主催者が使える）**で差別化。運営会社と競うのではなく、**主催者とコミュニティ運営者向けの道具**として位置づける。

### K7. 継続的な「回転」が必要で、開催が止まると売上が止まる【可能性: 中 / 致命度: 中】

- **理由**: イベント運営型は開催ごとの売上が立つ回転型だが、止めると売上も止まる（【二次】）。単発の需要では継続しない。
- **対策**: 会員制（月額で定期参加）、過去参加者の再来訪導線、コミュニティ化（イベント後のグループチャット）を設計に組み込む。既存の一体型コミュニティ案と接続する。

### K8. 外部要因・規制変更【可能性: 低〜中 / 致命度: 中】

- 景気、コロナのような感染症の再拡大、アプリ側の価格・機能変化、LINE などの規約変更。
- **対策**: 売上の特定の経路に依存しない。オンライン開催の選択肢を残す。
